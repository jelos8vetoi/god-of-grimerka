# AUDIO QUALITY GATE — «5 НОЧЕЙ С ПАХАНОМ», P1

Материалы для прослушивания. Что из чего сделано, источники и лицензии — `godot/docs/FIVE_NIGHTS_AUDIO_GATE.md`.

| звук | прежний | вариант A | вариант B | в игре |
|---|---|---|---|---|
| скример БАЛОНА | `balon_original.wav` | `balon_a_organic.wav` | `balon_b_physical.wav` | `ingame_balon.mp4` |
| переключение камеры | `cctv_original.wav` | `cctv_a_relay.wav` | `cctv_b_signal.wav` | `ingame_cctv.mp4` |
| MADK1D в шахте | `madk1d_original.wav` | `madk1d_a_heavy.wav` | `madk1d_b_unnatural.wav` | `ingame_madk1d.mp4` |

- WAV — сами файлы игры, без обработки сверху. `balon_original.wav` — `scream_balon_1.wav`, один из трёх прежних.
- `cctv_*.wav` — четыре щелчка подряд через 0,7 с: у прежнего это один и тот же звук, у вариантов — четыре дубля.
- `madk1d_original.wav` — прежние 1,6 с шесть раз подряд, как их играет игра; у вариантов — первый дубль из трёх.
- `ingame_*.mp4` — запись самой игры (Godot Movie Maker, звук и кадры идут из игры вместе): подряд ORIGINAL, VARIANT A,
  VARIANT B в одинаковых условиях, надпись в углу говорит, что играет. Своя ночь без врагов.
  - `ingame_balon.mp4` — три скримера (ночь, удар, экран гибели), в конце перезапуск ночи во время крика.
  - `ingame_cctv.mp4` — шесть переключений, потом восемь быстрых. Подъём и опускание планшета — прежний звук, он не менялся.
  - `ingame_madk1d.mp4` — MADK1D в шахте (7 с), у решётки (9 с), уходит. Удар по решётке при подходе — прежний звук.
