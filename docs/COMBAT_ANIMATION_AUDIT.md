# Аудит боевых анимаций и план (2026-11-17)

Документ отвечает на задачу «COMPLETE COMBAT ANIMATION AUDIT & FOUNDATION» и на три задания по стилям Пахана
(Балон VOZDUH, Водяра, ТЯГА-812). Здесь — что есть на самом деле, чего нет и в каком порядке делать.
**Стили по этим заданиям ещё не переделывались — жду одобрения плана.**

Числа ниже — не из головы, а из инструмента аудита:

```bash
tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --script res://scripts/animaudit.gd
```

Он читает данные проекта (клипы героев, роли, атаки и связки стилей) и печатает строки `AUDIT …`.
В заданиях пылесос назван «ТЯГА-808» — в проекте он переименован в **ТЯГА-812**, дальше так.

## 1. Как это устроено сейчас

| Вопрос из задания | Ответ |
|---|---|
| Как делаются анимации | Позами в коде: клип — словарь `{"d", "k": [[доля, поза, IK?, плавность]], "ground", "ev", "root", "spin"…}`. `rig.gd` запекает его по кадрам в `AnimationPlayer`. Готовых анимаций в `.glb` нет. |
| Как адресуются кости Mixamo | Таблица `Rig.BONES` (короткое имя → имя кости); поза задаёт повороты костей в радианах относительно позы покоя. Руки с оружием ведёт IK: `Poses.W(где кулак, куда смотрит оружие, {"two": вторая рука})`. |
| Как смешиваются позы | Между ключами — с плавностью ключа (`"in"`, `"out"`, `"io"`, `"lin"`); между клипами — время смешения `AnimationPlayer` (у каждого перехода своё в `PROFILE`). Поверх — слои `SkeletonModifier3D`: стопы (`foot_ik.gd`), инерция балона (`drag.gd`), iPod в руке (`pod.gd`). |
| Как запускаются атаки | Ввод → буфер ядра боя (`combat.press`, 0,3 с) → `combat.try_start()` → `AttackData` из графа стиля (`StyleData.links`). Клип играет `rig.play_for(a.clip, a.duration)`. |
| Хитбоксы и окна урона | `AttackData.hits` — доли клипа; попадание — сектор (`reach`, `arc`) или sweep-хитбокс оружия перед моментом удара (`hit_lead`). Цель получает `HitInfo` → `enemy.take_hit_info`. |
| Окна комбо и буфер | `combo_from…combo_to` атаки: только в этом окне буфер запускает следующую атаку графа. Перекат отменяет удар после `roll_from`. Смена стиля — только после попадания и не для всех видов атак (`WeaponFlow.NO_CANCEL`). |
| Реакции врагов | `enemy.reaction_for(h)`: семь реакций по массе и броне (этап 09). |
| Удары в воздухе и добивания | Удары в воздухе — обычные атаки графа после подброса. Добивания — `execution.gd`, отдельная система. |

## 3. Главные находки

1. **Балон: 25 атак на 10 клипах.** Upper играет в пяти атаках, FullSwing и Smash — в четырёх, Light1 — в трёх. Это прямое нарушение требования «не повторять одинаковые анимации»: разные удары выглядят одинаково.
2. **Водяра: все шесть атак — броски, и пять из них играют один клип `BottleThrow`.** Ближнего боя бутылкой нет вообще. Ответов после уклонения и парирования нет.
3. **У Пахана нет ударов в прыжке.** Прыжок появился сегодня; нажатие удара в воздухе запускает наземную цепочку с наземными клипами.
4. **Уклонение — один клип на все стороны** (`Tuck`, кувырок). Отдельных уклонений вбок, вперёд и назад нет.
5. **Блок — один клип.** Нет «тяжёлого блока» и нет реакции на принятый удар (`Block Impact`).
6. **Вариаций покоя у Пахана нет** (у madk1d есть: брейк-движения от безделья).
7. **ТЯГА-812: режимов езды, втягивания и выброса воздуха три, но связок между ними нет** (`links` пуст): каждый режим живёт отдельно. Нет заднего хода, торможения, тарана боком, «колена» после притягивания. С пылесосом в руках нельзя прыгать.
8. **Шланг пылесоса — часть цельной модели.** Он не гнётся и не может «не проходить сквозь Пахана» сам: костей у модели нет. Это ограничение модели, а не кода.
9. **49 клипов без событий.** Звук и частицы шагов, хвата и удара в них привязаны ко времени, а не к движению.

Сломанных переходов (зависаний, потери управления) проверки не находят: `--animcheck`, `--animlab`, `--flowcheck`, `--combatcheck` проходят.

## 9. Этап 1 — балон: сделано

По данным `animaudit.gd`: **34 атаки, 34 разных клипа**, общих клипов нет (было 25 атак на 10 клипах). Цепочка ЛКМ — пять ударов.

**Граф**

| Ввод | Что выходит |
|---|---|
| ЛКМ ×5 | боковой → обратный → ПЛЕЧОМ → СВЕРХУ ВНИЗ → ДОДАВИЛ (оборот всем телом, отбрасывает) |
| ЛКМ, ПКМ | подброс; дальше ЛКМ — ВДОГОНКУ (герой взлетает за целью) → ЛКМ С НЕБА → ПКМ В АСФАЛЬТ С НЕБА; ПКМ — вертушка; F — бутылка |
| ЛКМ ×2, ПКМ | полный замах (заряжается) |
| ЛКМ ×3, ПКМ | ПО НОГАМ — низкий круговой, сбивает с ног; дальше ЛКМ — подброс, ПКМ — удар по земле |
| ЛКМ ×4, ПКМ | вертушка |
| ПКМ; ПКМ / ЛКМ | удар сверху; дальше удар по земле или подброс рывком из приседа |
| в прыжке ЛКМ | мах; дальше ЛКМ — удар сверху → добивание с неба; ПКМ — удар сверху двумя руками |
| после уклонения | ЛКМ — низкий мах из приседа, ПКМ — подброс двумя руками (дальше ЛКМ — вдогонку) |
| после точного уклонения | ЛКМ — восходящий мах, ПКМ — подброс одной рукой с прыжком |
| после парирования | ЛКМ — тычок торцом, ПКМ — ответ наотмашь двумя руками |
| из блока | толчок балоном от себя |
| с разгона | ЛКМ — мах на бегу, ПКМ — таран плечом |
