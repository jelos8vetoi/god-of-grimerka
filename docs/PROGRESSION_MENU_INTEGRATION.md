# Прокачка: всё через вкладку «РАЗВИТИЕ»

Постоянное правило: любая система RPG-прокачки подключается к игроку через вкладку **РАЗВИТИЕ** меню паузы (`godot/scripts/pausemenu.gd`, `_open_page(1)`). Отдельные экраны прокачки, вторые магазины и новые вкладки под прокачку не создаются.

## Что есть сейчас
- Три улучшения по пять уровней: `hp` (здоровье +20), `dmg` (сила +12% урона), `q` (ад-либ madk1d на 1,5 с чаще).
- Данные: `game.xp` (прослушивания), `game.up`, цена — `game._cost(k)`, эффект — `game._apply_upgrades()`.
- Покупка из паузы — только `game.buy_upgrade(k)`: не двигает сюжет, не лечит (кроме +20 от самого улучшения здоровья), сохраняет игру.
- `game._open_shop()` (мастерская дяди Севы) — сюжетный шаг: по закрытии зовёт `next_step()`. Из паузы его вызывать нельзя.

## Что сюда добавится
Деревья навыков Пахана и madk1d, шесть боевых стилей, улучшения оружия, мастерство, активные и пассивные способности, Team Tag, Team Hype, командные способности.

## Как добавлять
1. Данные и эффекты — в игровой логике, с функцией покупки по образцу `buy_upgrade`: проверка цены, списание, применение, сохранение — без побочных шагов сюжета.
2. В `PauseMenu._open_page(1)` — новые строки и действия карточки (или подстраницы внутри РАЗВИТИЯ, если пунктов станет много).
3. Не показывать заготовки как работающие: пока системы нет в игре, её нет и в меню.
4. Дополнить проверку `--ipodcheck --pause` покупкой нового типа.
