# Установщик GOD OF GRIMERKA

Отдельное приложение `GOD-OF-GRIMERKA-Setup.exe` (около 480 КБ) с рисованным окном в дизайн-системе игровых меню.

## Как устроен
- Исходник — один файл `tools/setup/Setup.cs` (C#, WinForms + GDI+), собирается компилятором .NET Framework 4, который есть в любой Windows 10/11.
- Сцена рисуется на «столе» 1600×900 и вписывается в окно любого размера. Фон (мазки, кольца, силуэт города), рваные плашки и зерно рисуются кодом; звуки синтезируются при запуске.
- Герои — `tools/setup/heroes.png`: рендер настоящих моделей из главного меню. Обновить после смены моделей:
  `tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot -- --menu-render=<полный путь>/tools/setup/heroes.png`
- Установщик онлайн: игру (`GOD-OF-GRIMERKA-Godot.exe`) и лаунчер качает из релиза `godot-build` и сверяет SHA-256, который сообщает GitHub.

## Что оказывается на диске
- Папка установки (по умолчанию `%LOCALAPPDATA%\Programs\GOD OF GRIMERKA`): `GOD OF GRIMERKA.exe`, `GOD OF GRIMERKA Launcher.exe`, `Uninstall.exe` (копия установщика), `installed.txt` (версия игры), `grimerka-install.txt` (метка: лаунчер держит игру в своей папке).
- Ярлыки на рабочем столе и в меню «Пуск» ведут на лаунчер.
- Запись об удалении — `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\GodOfGrimerka`; права администратора не нужны.
- Данные игрока (`%APPDATA%\Godot\app_userdata\GOD OF GRIMERKA`: сохранение, настройки, музыка iPod) установщик не создаёт и не трогает; удаляет только при отмеченной галочке на экране удаления.

## Сборка
`tools\setup\build.cmd` → `dist\GOD-OF-GRIMERKA-Setup.exe`. Автосборка (`tools/publish-godot.cjs`) собирает его и кладёт в релиз рядом с игрой и лаунчером.

## Проверка
Ключи запуска:
- `--shots=<папка>` — снимки всех экранов на 1920×1080 и 1366×768 (плюс вступление и установка на 2560×1440 и 1280×800);
- `--auto --id=<Имя> --dir=<папка> --log=<файл>` — установка без кликов под отдельным именем (свои ярлыки и запись в реестре, настоящая установка не задевается);
- `--fake-free=<байт>` — проверка отказа при нехватке места; `--cancel-at=<процент>` — отмена посреди загрузки;
- `--no-desktop`, `--no-start`, `--launch` — опции;
- `--uninstall` (экран удаления), с `--auto` — без кликов; `--wipe-data --data-dir=<папка>` — проверка удаления данных на подставной папке.

Проверенный сценарий (2026-11-16): отказ при 1 МБ свободного места; отмена на 30% — папка не остаётся; установка — три файла, оба ярлыка, запись в реестре, SHA-256 игры совпал с релизом; повторная установка — игра не качается заново; игра запускается из папки; лаунчер из папки установки не уходит в свою старую папку; удаление — файлы, ярлыки и запись убраны, чужой файл в папке и данные игрока остаются; удаление с галочкой стирает подставную папку данных; `Uninstall.exe` удаляет сам себя и пустую папку.

## Ограничения
- Нужен интернет: игра не вшита в установщик.
- Файл не подписан — Windows SmartScreen при первом запуске попросит «Подробнее → Выполнить в любом случае».
- Фонового звука нет, только короткие звуки интерфейса (выключаются кнопкой SOUND).
- Выбор папки — системное окно Windows.
