# Боевая анимационная основа (этап 02)

Основа, на которую по одному добавляются шесть стилей боя (`docs/COMBAT_SYSTEM_ROADMAP.md`).
Внешний вид персонажей не менялся: те же модели, тот же балон, позы — только новые клипы и правки рига.

## Из чего состоит

| Часть | Файл | Что даёт |
|---|---|---|
| Роли анимаций | `rig.gd` → `ROLES`, `role_clip`, `play_role`, `play_role_for`, `style_map` | контроллер просит роль («sprint», «parry», «knockdown»), риг находит клип; стиль подменяет клипы своими через `style_map` |
| События в клипах | `rig.gd` → `signal clip_event(clip, ev)`, ключ `"ev"` в описании клипа | шаг, хват, касание земли, момент удара — по положению самой анимации (верно при любой скорости, стоп-кадре, замедлении, в циклах — на каждом круге) |
| Чехол оружия | `rig.gd` → `setup_holster`, `set_holstered`; `Poses.PH_HOLSTER_*` | балон за спиной и обратно в кулак точно на место; в чехле `weapon_bone = -1`: инерция (`drag.gd`), след и `weapon_points` молчат; роли берут клипы «…Bare» |
| Устойчивый IK рук | `rig.gd` → `_ik_arm`, `IK_HAND_BIAS`, `IK_ELBOW_BIAS` | кисть и локоть больше не перескакивают на другую сторону за кадр, когда оружие смотрит вдоль руки |
| Циклы шага на полу | `rig.gd` → `"smooth"` + `"ground"` | в беге, шаге и рывке таз в каждом ключе ставится так, что опорная стопа на полу (раньше стопы тонули до 5 см) |
| Клипы | `poses.gd` → `_pahan_combat`, `madk1d_combat` | см. таблицу ниже |
| Отклик боя | `feedback.gd` (`Feedback.EVENTS`), `game.feedback(name, pos, dir, mul, col)` | одно имя события → стоп-кадр, тряска, экранный удар, частицы, звук, надпись, след, подтверждение попадания |
| Проверка | `animcheck.gd`, ключ `--animcheck` | см. «Проверка» |

## Как добавить стиль (кратко)

1. Клипы стиля — в `poses.gd` (как `_pahan_combat`): подготовка `"out"` → разгон `"in"` → удар → довод `"out2"` → возврат `"io"`;
   у ударов с оружием — хват `W(точка, направление)`, переходы через землю — через ключ `side`, чтобы оружие не уходило под пол.
2. События стиля — ключ `"ev"` (`"hit"`, `"grab"`, `"land"`…), контроллер слушает `rig.clip_event`.
3. `rig.style_map = {"light": "…", "heavy": "…"}` при выборе стиля; смена оружия — `Equip`/`Unequip` + `set_holstered` на событиях.
4. Отклик — новые строки в `Feedback.EVENTS`, вызов `game.feedback(...)`.
5. `--animcheck` — добавить клипы в списки `*_SEQ`, прогнать, посмотреть раскадровки.

## Проверка

```bash
tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot --resolution 1280x720 -- --animcheck=<папка> [--noshots]
```

Печатает по каждому клипу обоих героев: стопы на полу (`ground`; в циклах — касание без провала), низшая точка балона,
наибольший поворот кости за 1/160 клипа (перескок IK остаётся большим при любом шаге, быстрый удар — нет), стык цикла;
проверяет роли, подмену стилем, события (на половинной скорости, циклы — по два с лишним круга), чехол и стык «рука у чехла».
Итог — `ANIMCHECK ok` или `ANIMCHECK ОШИБОК: n`. Раскадровки — `seq_<pahan|madk1d>_<клип>.png` (16 кадров, две стороны).
Отдельные листы — `--posesheet=<папка>,pahan_combat` и `--posesheet=<папка>,madk1d`.

## Состояния и переходы (`AnimState`)

Контроллер каждый кадр вызывает `anim.tick(dt, скорость, нужный_доворот, на_земле, vy, враги_рядом, рывок)`; удары и реакции — `anim.action(роль, длительность)`, прыжок — `anim.jump()`.

```
idle ──появилась скорость──▶ start ──(start_t)──▶ move: walk / run / sprint (по скорости или рывку)
move ──скорость пропала (была > stop_min)──▶ stop ──(stop_t)──▶ idle / combat_idle
idle ──доворот > turn_min──▶ turn_l / turn_r ──▶ idle
любое ──не на земле, vy < −1──▶ fall ──земля──▶ land ──(land_lock)──▶ idle / move
любое ──action()──▶ action ──(hold)──▶ дальше по скорости
клип поставил контроллер напрямую (удары player.gd) ──▶ external ──▶ сразу idle/move, без старта и остановки
```

Длительности, пороги и смешивание — в `PROFILE` персонажа (`roles` переводит роль в клип: `start` → `StartRun`).
**Пахан тяжёлый:** старт 0,32 с, остановка 0,5 с (балон по инерции выносит вперёд), поворот 0,55 с переступанием, на старте разворачивается вдвое медленнее.
**madk1d быстрый:** старт 0,13 с, остановка 0,24 с, поворот 0,24 с, приземление 0,25 с, смешивание вдвое короче.

**Скорость шага.** Для клипов шага AnimState сам считает длину шага (`stride()`: насколько опорная стопа уезжает назад за круг) и ставит `speed_scale = скорость тела × длина клипа / шаг` — ноги идут ровно со скоростью тела. `rig.play` / `play_for` сбрасывают `speed_scale` для остальных клипов.

**Root motion** — только там, где тело переносит сама анимация: рывок madk1d (3,2 м), прыжковая атака, аэрокомбо (подъём и пикирование), подъём разгибом. Ключ клипа `"root": [[доля, вперёд м, вверх м], …]`, вращение — `"spin"` (оборотов) и `"spin_win"`. Контроллер забирает смещение за кадр через `anim.root_step()` (у madk1d — `companion.apply_root()`). Удары Пахана по-прежнему двигают тело шагом из таблиц `player.gd`.

## Стопы (`FootIK`)

Слой после анимации (как `drag.gd`): луч в землю под каждой стопой, двухзвенный IK ноги, стопа сохраняет поворот. Опорная стопа, которая в анимации стоит и почти не движется, прибивается к месту касания и отпускается, когда тело уходит от неё дальше 8 см (переступание). `weight` — прилегание, `lock` — фиксация. Контроллер выключает фиксацию в ударах (там тело шагает само), а всё — в перекате, гибели и полёте.
Руки на полу (шесть шагов, фриз madk1d) — IK кисти ключом `{"l": …}` в клипе.

## Где это видно в игре сейчас

- Пахан: старт с упором, остановка с выносом балона, шаг / бег / рывок без скольжения ног, разворот на месте (`player.turn_to`), падение и приземление при сходе с высоты, реакции на удар спереди, сзади, слева, справа, отброс.
- madk1d: короткие старты и остановки, рывок, когда отстал, повороты переступанием, а когда долго стоит без врагов — брейк (шесть шагов, фриз, смена стойки).
- Удары, прыжковые и воздушные приёмы madk1d, нокдаун и подъём, прыжок Пахана — пока только в проверке: бой madk1d и прыжок — следующие этапы.

## Проверка в игре

```bash
tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot --fixed-fps 30 --resolution 1280x720 -- --animlab=<папка> [--only=01,09] [--trace] [--nofootik]
```

Девять сцен в настоящей главе, листы `lab_<сцена>.png` по 16 кадров: перемещение Пахана, удар, комбо, урон с четырёх сторон и отброс, нокдаун — подъём — прыжок, удары madk1d, аэрокомбо, брейк, перемещение madk1d.
