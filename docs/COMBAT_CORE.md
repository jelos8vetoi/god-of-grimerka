# Ядро боя (этап 04)

Одна боевая система на все шесть стилей. Стиль — это данные (атаки и граф комбо), ядро — код, который ведёт удар
от нажатия до конца. Балон VOZDUH полностью работает на ядре; урон, длительности и окна ударов взяты из прежних таблиц `player.gd` без изменений.

## Файлы

| Файл | Что |
|---|---|
| `attack_data.gd` (`AttackData`, Resource) | одна атака: id, тип, урон, равновесие, дистанция, сектор, радиус, длительность, моменты и окно попадания, окна комбо и отмены, перезарядка, клип, шаг, эффекты, звук |
| `style_data.gd` (`StyleData`, Resource) | стиль: оружие, атаки, граф комбо `links`, Heat-цепочка, атаки после уклонения, буфер, пауза против спама, звуки и цвета; `problems()` проверяет данные |
| `style_vozduh.gd` | таблица стиля «Балон VOZDUH» |
| `styles.gd` (`Styles`) | реестр шести стилей: `Styles.by_id("vozduh")`, `Styles.of("pahan")`; будущие стили объявлены заглушками (`ready = false`) |
| `combat.gd` (`Combat`) | ядро: буфер ввода, фазы атаки, окна, попадания, урон, перезарядки, цель |
| `hit_info.gd` (`HitInfo`) | одно попадание: урон, равновесие, направление, отбрасывание, подброс, оглушение, сила, id атаки и стиля |
| `enemy.gd` → `take_hit_info`, `stagger`, `slow` | приём попадания, равновесие, замедление |
| `combatcheck.gd` | проверка в игре (`--combatcheck`) |

## Путь удара

```
нажатие → буфер (0,3 с) → из стойки: links[""][ввод]  →  атака: замах → попадание → завершение
                                                             │ окно комбо [combo_from, combo_to]: буфер → links[атака][ввод]
                                                             │ отмена перекатом после roll_from (по умолчанию после первого попадания)
                                                             └ recovery: герой свободен; оборванная цепочка → пауза chain_cd
```

- **Буфер ввода.** Нажатие помнится `style.buffer` секунд. Нажал чуть раньше окна — цепочка продолжится; нажал в самом замахе — нет. Раньше любое нажатие за время удара ставило следующий удар в очередь.
- **Окно комбо.** `combo_from … combo_to` атаки. Куда ведёт ввод — граф `links`: `{"vz_light1": {"light": "vz_light2", "heavy": "vz_nail"}}`. Тяжёлые (`heavy`) цепочку не продолжают.
- **Против спама.** После цепочки, которая оборвалась сама, новый лёгкий удар возможен через `chain_cd` (0,15 с). У атаки может быть своя перезарядка `cooldown`.
- **Попадание.** С момента `hits[i]` открыто окно `hit_window`: каждый кадр проверяются дистанция и сектор; цель задевается одним моментом удара один раз (журнал попаданий). `detect = "sweep"` добавляет хитбокс самого оружия: отрезок оружия и путь его конца за кадр против капсулы врага (радиус и высота — хёртбокс), открывается за `hit_lead` до момента удара.
- **Урон.** `Combat.damage_for()`: база × ПЕРЕГРУЗ × `player.dmg_mul` (прокачка). Одна точка для будущих навыков и мастерства.
- **Равновесие.** У обычного врага 60, у босса 200. Атака снимает `stagger`; кончилось — «СБИТ»: обычный враг оглушён на секунду даже в замахе, босс вздрагивает. Через 2 с без ударов восстанавливается. В воздухе, лёжа, в оглушении и в особом приёме босса не снимается.
- **Отклик.** Событие `Feedback` по силе атаки (`power` 0/1/2) или своё (`feedback`), звуки попадания стиля (`hit_sfx`) или атаки (`sfx_hit`), след оружия (`trail_boost`), удар в землю (`slam`), скрежет (`scrape`), падение оружия (`drop`).
- **Сигналы ядра:** `attack_started`, `attack_hit`, `attack_ended` — для HUD, навыков и проверок.

## Как добавить стиль

1. `style_<имя>.gd` с `static func build() -> StyleData`: оружие, `AttackData.make({...})` на каждую атаку, `links`, при необходимости `heat`, `after_dodge`, `roles`.
2. Строка в `Styles._make()`.
3. Клипы стиля — в `clips_*.gd` / `moves_*.gd`; доли `hits`, `step`, `slam` совпадают с ключами клипа.
4. `--combatcheck` и `--animcheck`.

Код ядра менять не нужно, пока стиль укладывается в «атака с моментами попадания». Дистанционные и особые режимы (бутылки, ТЯГА-812) добавляют свои контроллеры рядом с ядром, но урон наносят тем же `HitInfo`.

## Проверка

```bash
tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot --fixed-fps 30 --resolution 1280x720 -- --combatcheck=<папка>
```

В настоящей главе, на боте, клиппере и хейтере: данные шести стилей, клипы атак, урон только в момент попадания, один удар — один раз по каждой цели, цепочка лёгких, четыре ветки «n лёгких → тяжёлый», буфер (слишком рано — нет, чуть раньше окна — да), отмена перекатом (в замахе — нет, после попадания — да), пауза против спама, перезарядка, равновесие, sweep-хитбокс, Heat-цепочка, заряд. Итог — `COMBAT итог: ошибок 0`.

# Стиль «Балон VOZDUH» (этап 05)

Тяжёлое оружие: медленный замах, сильный удар, заметное равновесие, отбрасывания. Все удары — данные в `style_vozduh.gd`.

| Удар | id | Как вызвать | Особенность |
|---|---|---|---|
| Быстрый боковой | `vz_light1` | ЛКМ | первый удар цепочки |
| Наотмашь (двойной) | `vz_light2` | ЛКМ, ЛКМ | |
| Подброс (launcher) | `vz_upper` | ЛКМ ×3 | подбрасывает врага |
| В землю | `vz_slam` | ЛКМ ×4 | подброшенного вбивает в землю (удар в воздухе) |
| Удар сверху | `vz_overhead` | ПКМ | удержание — замах над головой, до +50 % урона |
| Удар по земле | `vz_quake` | ПКМ, ПКМ | новый: прыжок и удар вокруг себя, подбрасывает всех рядом |
| ГВОЗДЬ | `vz_nail` | ЛКМ, ПКМ | оглушает |
| Полный замах (боковой) | `vz_fullswing` | ЛКМ ×2, ПКМ (держать) | заряжается, далеко отбрасывает |
| Вертушка (с разворота) | `vz_spin` | ЛКМ ×3, ПКМ | серия ударов вокруг |
| С ходу | `vz_roll_swing`, `vz_roll_launch` | ЛКМ или ПКМ в течение 0,35 с после переката | новые: клип стартует с середины — балон уже в движении; дальше идёт обычная цепочка |
| Heat | `vz_heat_smash` → `vz_heat_swing` | E при 40 СВЭГа | |

Отклик по весу удара (`Feedback.EVENTS`): стоп-кадр лёгкого 0,055 с < подброса 0,085 < тяжёлого 0,12 < завершающего 0,13 < удара в землю 0,14 < удара по земле 0,16; тяжёлые попадания поднимают пыль под целью, удар по земле — кольца и пыль вокруг.
Равновесие: лёгкие снимают 14–18, тяжёлые 40–50, удар по земле 70, Heat 60–80 (у врага 60, у босса 200).
Прежние удары, их урон, длительность и окна не менялись; короткое нажатие ПКМ даёт тот же удар сверху, что и раньше.

## Балон: контратаки, разгон, Heat (расширение)

Особые окна (`StyleData.after`, `Combat.open(имя, сек)`): сразу после события ввод ведёт к своей атаке; клип стартует с середины — балон уже в движении. Порядок важности: парирование, идеальный уклон, блок, уклон, разгон.

| Когда | ЛКМ | ПКМ |
|---|---|---|
| Парировал (0,8 с) | `vz_parry_light` — гвоздь, оглушает | `vz_parry_heavy` «ОТВЕТКА» — полный мах без заряда, 70 урона |
| Идеальный уклон «ТАЙМИНГ!» (0,7 с) | `vz_perfect_swing` — мах, 52 урона | `vz_perfect_launch` — высокий подброс |
| Принял на блок (0,5 с) | `vz_block_shove` — толчок наотмашь, отгоняет | то же |
| Перекат (0,35 с) | `vz_roll_swing` | `vz_roll_launch` |
| На бегу с Ctrl | `vz_dash_swing` «С РАЗГОНА» — героя несёт вперёд, перезарядка 1,2 с | `vz_dash_slam` — прыжок с ударом в землю, перезарядка 2 с |

Новые связки: ПКМ, ЛКМ — удар сверху → подброс (`vz_rise`), дальше ЛКМ вбивает в землю, ПКМ — вертушка.

**Heat (E, 40 СВЭГа)** — вариант по положению цели (`StyleData.heat_ctx`): цель на ногах — удар сверху и полный замах (как раньше); оглушена или лежит — «ДОБИЛ», удар сверху в лежащего, 95 урона; в воздухе — подброс и «В АСФАЛЬТ».
**СВЭГ:** за попадание 6 на цель и ещё 4, если этого удара не было среди четырёх последних (разные удары копят быстрее); парирование +20, идеальный уклон +12, блок +3. При СВЭГе от 70 след балона раскалён.
**Ограничения:** удары с разгона имеют перезарядку; окна контратак короткие и расходуются одним ударом; равновесие боссов 200 — «ОТВЕТКА» и добивание их не сбивают с одного удара; Heat по-прежнему стоит 40 СВЭГа.

# Стиль «Водяра» (этап 06)

Дистанционный стиль Пахана: контроль и подготовка комбо, не урон. Данные — `style_bottles.gd`, полёт и всплеск — `bottles.gd`, клипы — `clips_bottles.gd`, модель — `assets/models/bottle.glb`.

**Смена стиля.** `[1]` — Балон, `[2]` — бутылки (`player.set_style`, 0,42 с): балон уходит за спину в чехол по событию клипа `Unequip` и возвращается по `Equip`. Менять можно из стойки и из удара после его попадания; удар, нажатый во время смены, срабатывает сразу после неё. Пока балон в чехле, риг сам берёт клипы без хвата (`…Bare`).

| Действие | id | Как | Что делает |
|---|---|---|---|
| Быстрый бросок | `bt_quick` → `bt_quick2` → `bt_quick3` | ЛКМ до трёх раз | 9 урона, равновесие 22, замедление ×0,6 на 2,5 с, сбивает слабый замах; третий — с долгим завершением |
| Усиленный | `bt_power` | ПКМ держать — прицел с траекторией, отпустить | 16 урона (до +60 % от удержания), равновесие 45, оглушение 0,9 с, всплеск 2,2 м мочит соседей |
| С ходу | `bt_roll` | ЛКМ в течение 0,35 с после переката | быстрый бросок без замаха |

**Цель.** Бутылка летит в ближайшего врага в секторе перед героем (до 14–16 м), иначе — вперёд по взгляду; при удержании герой доворачивается за камерой и движением. Полёт баллистический; попадание — путь бутылки за кадр против капсулы врага, по окружению — луч.
**Запас.** 6 бутылок, одна восстанавливается за 3 с (всегда, и в другом стиле); пусто — бросок не начинается. В HUD: `[2] Водяра ●●●●○○`.
**Переходы в ближний бой.** Бросок → `[1]` → ПКМ: тяжёлый удар балоном через ~0,5 с после вылета бутылки. Усиленный бросок оглушает — время подойти и начать комбо.
**Общее с ядром.** Атаки бутылок — те же `AttackData` с полями `projectile`, `ammo`, `extra`; в момент «попадания» ядро зовёт `player.launch_projectile`, урон наносит снаряд тем же `HitInfo`. У врагов добавлены `slow()` и `interrupt_weak()`.
Звук всплеска синтезируется в коде (записи воды в проекте нет), стекло — `sfx_glass`. Броска в воздухе нет: у Пахана пока нет прыжка в управлении.

## «Водяра»: двойной, веер, воздух, бросок из комбо (расширение)

| Действие | id | Как | Что делает |
|---|---|---|---|
| Двойной | `bt_double` | ЛКМ, ЛКМ, ПКМ (или после переката ЛКМ, ПКМ) | две бутылки сразу — в двух врагов или обе в одного; тратит 2 |
| Веер | `bt_fan` | ЛКМ ×3 | три бутылки по трём целям в широком секторе (без целей — веером вперёд); тратит 3, долгое завершение. Заменил третий одиночный бросок |
| Бутылка из комбо | `vz_bottle` | `F` в стиле Балона — из стойки или в окне комбо | бросок левой рукой, балон остаётся в правой, стиль не меняется; тратит запас «Водяры»; дальше ЛКМ и ПКМ продолжают цепочку балона |

- **Цель в воздухе и на бегу.** Бросок берёт упреждение по скорости цели; подброшенного бутылка догоняет в воздухе и сбивает равновесие в полтора раза сильнее. Связка: ЛКМ ×3 балоном (подброс) → `F`.
- **Запас один на всё:** `F` тратит те же шесть бутылок (`extra.ammo_style`); в HUD балона — `[1] Балон VOZDUH   [F] ●●●●●`.
- **Предел объектов:** в воздухе не больше 12 бутылок, лишняя (самая старая) разбивается на месте; каждая живёт не дольше 3 с.
- **Баланс.** Дальность 14 м (усиленный 16, из комбо 12); скорость 16–21 м/с; подготовка 0,22–0,33 с; урон 8–16 против 28–95 у балона; серия «ЛКМ ×3» с веером тратит пять бутылок из шести.
- **Не сделано:** бросок с прыжка — у Пахана нет прыжка в управлении.

# Стиль «ТЯГА-812» (этап 07)

Пылесос с тремя режимами. Клавиша `[3]`. Контроллер — `tyaga.gd` (`Tyaga`, узел в `player.body`; герой в состоянии `"tyaga"`), числа — `style_tyaga.gd` (`AttackData` + таблицы `RIDE` и `HEAT`), точки модели и клипы — `clips_tyaga.gd`, модель — `assets/models/tyaga812.glb`.

**Модель и крепление.** Модель — один кусок (корпус на колёсах, шланг, труба со щёткой). Её точки — сиденье, три хвата на трубе, сопло — измерены по вершинам и записаны в `TyagaClips` в метрах. Пылесос не «приклеен» к руке: он стоит на земле рядом с героем в положении `V_HOLD` (на ногах) или `V_RIDE` (верхом), а руки приходят на трубу через IK клипов. При выборе стиля он выкатывается из-за спины, при посадке — подкатывается под героя, пока тот прыгает на корпус; ничего не возникает на месте.

| Режим | Управление | Что делает |
|---|---|---|
| На ногах | WASD — шаг с пылесосом, Shift — перекат, E — сесть | обе руки на трубе, сопло впереди |
| MODE 2 — притягивание | держать ЛКМ | поток из сопла по взгляду камеры: конус 7 м; тянет постепенно (чем ближе, тем сильнее), не больше трёх врагов сразу; сбивает слабый замах; у сопла враг пойман — оглушён и получает 4 урона каждые 0,3 с; вражеские снаряды втягивает. Боссов и тяжёлых (выше 2,2 м) не берёт — только придерживает |
| MODE 3 — выброс | ПКМ — воздушный выстрел; держать 0,45 с — «ПЕРЕГРУЗКА ДАВЛЕНИЯ» | выстрел: конус 6,5 м, 14 урона, отбрасывает, сбивает замах. Выброс: 5 м вокруг сопла, 30 урона, подброс и отброс группы, отдача толкает героя назад; пойманные притягиванием получают ×1,5. Снаряды сдувает |
| MODE 1 — езда | E — сесть / сойти; WASD — куда ехать; Ctrl — ускорение; Shift — занос; пробел — прыжок; ЛКМ — удар с разворота; ПКМ — выстрел | до 10,5 м/с (14,5 с ускорением); руление с инерцией; в заносе сцепление падает — тело несёт боком, искры; занос + назад — разворот на месте; назад без заноса — тормоз; прыжок; таран на скорости от 5 м/с (урон 10 + 1,2 за каждый м/с, отброс по скорости); удар с разворота бьёт вокруг; о стену — удар и потеря скорости; урон по герою сбивает с пылесоса |

**Нагрев.** Притягивание (16/с), выброс (25 / 55), ускорение (20/с), удар с разворота (10) греют; остывает 22/с. На 100 — «ПЕРЕГРЕВ»: 2,5 с режимы не работают, из корпуса идёт дым. В HUD: `[3] ТЯГА-812  нагрев ▮▮▮▯▯▯▯▯  [E] сесть`.
**Посадка героя.** Верхом таз стоит над сиденьем корпуса (проверка: смещение 0,01 м, выше на 0,10 м), правая рука на трубе-рычаге, ноги на крышке; корпус и герой кренятся вместе в повороте. IK стоп верхом выключен.
**Звук.** Гул мотора синтезируется в коде и меняется по режиму и скорости (записи пылесоса в проекте нет); выброс — `sfx_wave` и `sfx_boom`.
Предметов для подбора в игре сейчас нет, поэтому из «объектов» поток забирает вражеские снаряды.

## ТЯГА-812: бросок пойманного, всасывание, соскок (расширение)

- **Бросок пойманного** (`tg_throw`, `tg_bowl`): пока враг у сопла, короткое ПКМ (до 0,18 с) — он вылетает вперёд (12 урона, отброс 20) и 0,8 с сбивает тех, в кого попадёт (16 урона каждому, по разу). Долгое ПКМ по-прежнему заряжает выброс.
- **Всасывание ослабленных:** пойманного обычного врага с четвертью здоровья и меньше затягивает целиком («ВСОСАЛ»); +8 СВЭГа, +8 нагрева. Боссов и тяжёлых поток не берёт вовсе, так что их это не касается.
- **Соскок на ходу** (`tg_leap`): E на скорости от 5 м/с — прыжок с пылесоса с ударом вокруг (20 урона, 2,6 м) и окно 0,9 с для удара «с ходу» после смены стиля.
- **Таран на ускорении:** от 12 м/с таран подбрасывает врага («ТАРАН»).

# Реакции врагов и добивания (этап 09)

## Реакции

Одна точка входа — `enemy.take_hit_info(HitInfo)`. Какая будет реакция, решает `enemy.reaction_for(h)` по таблице `enemy.REACT` (масса, броня, можно ли подбросить и сбить с ног) и по удару (`stagger`, `heavy`, `power`, `launch`, `knockback`, подсказка `HitInfo.react` из `AttackData.extra.react`). Масса делит отбрасывание и снятое равновесие.

| Реакция (`enemy.react`) | Что видно | `react_state()` |
|---|---|---|
| `none` | броня: вспышка и урон, враг продолжает своё | NORMAL |
| `hit` | короткая реакция, 0,35 с | HIT |
| `stagger` | сбит на 0,6 с | STAGGER |
| `heavy_stagger` | согнулся на 1 с | HEAVY_STAGGER |
| `knockback` | уезжает назад, 0,75 с | KNOCKBACK |
| `knockdown` | падает, лежит, встаёт | AIRBORNE → KNOCKDOWN → RECOVERY |
| `airborne` | подброшен | AIRBORNE |

| Враг | Масса | Особенность |
|---|---|---|
| бот, юрист | 1,0 | все реакции |
| клиппер, накрутчик, хейтер | 0,9 / 0,85 / 0,75 | лёгкие: отлетают дальше |
| призрак | 0,6 | с ног не сбить (подсечка даёт heavy_stagger), отлетает дальше всех |
| модератор | 1,35, броня 8 | лёгкий удар его не сбивает |
| тролль | 2,6, броня 14 | лёгкий удар не замечает; не подбрасывается, не падает, не отлетает |
| босс | 3,0, броня 10 | реагирует только на тяжёлое; не подбрасывается и не падает |

## Добивания (`execution.gd`, `Execution`)

`[E]` рядом с врагом, у которого над головой красный крест. СВЭГ не тратит, а даёт (+15, по обстановке +22). Враг готов (`enemy.exec_ready()`), когда он оглушён, согнулся, отлетает, лежит, встаёт или в воздухе и здоровья не больше 40 %; почти мёртвого (15 %) можно добить в любом состоянии. Длятся 0,6–1,0 с, герой на это время неуязвим.

| Стиль | Добивание | Чем кончается |
|---|---|---|
| Балон | ПРИГОВОР | удар сверху, вбивает в землю |
| Водяра | РОЗОЧКА | бутылка в упор, всплеск |
| ТЯГА-812 | НА ВЫДУВ | притягивает к раструбу и выстреливает прочь |
| Скейтборд | ДЕКОЙ В ПОЛ | подбив снизу и удар доской сверху |
| Гитара | ПОСЛЕДНИЙ АККОРД | удар гитарой, аккорд и разряд |
| Breaker | НОКАУТ | вертушка ногами в прыжке, враг улетает вверх |

Обстановка меняет название, скорость и концовку: цель в воздухе — AIR FINISHER (прыжок и удар вниз); в окне после парирования — PARRY FINISHER; в окне после уклонения — COUNTER FINISHER (оба в 1,4 раза быстрее и берут врага с запасом здоровья до 60 %, в любом состоянии).

Командное добивание (этап 10) подключается через `Execution.team_hook` — вызов на последнем ударе; сигнал `executed(enemy, style_id, ctx)`.

## Боссы

Добить нельзя (`exec_ready()` всегда false). Срыв равновесия открывает босса на 1,4 с: замах сорван, надпись «ОТКРЫТ», урон по нему ×1,3 (`weak_t`). После каждого окна равновесие крепче на четверть. Во время особого приёма равновесие не снимается. Heat по боссу работает как раньше.

Проверка: `--resolution 1280x720 -- --execcheck=<папка>` — восемь типов врагов, шесть стилей, обстановка, босс; «EXECCHECK ok».

# Tag Team (этап 10)

`tagteam.gd` (`TagTeam`, `game.tag`). Игрок ведёт одного героя, второй — напарник (`companion.gd`).

## Смена героя — `[Tab]`

- У каждого героя своё здоровье (`tag.hp`); стиль, запасы и перезарядки каждого сохраняются. СВЭГ общий.
- Герои меняются местами: управление переходит к тому, кто стоял рядом.
- Нельзя сменить: пока героя бьют, в середине уклонения, в добивании, в смене стиля, в ПЕРЕГРУЗе, пока напарник выбыл (`tag_block()` говорит почему).
- Пауза между сменами — 2 с, после командного приёма — 5 с.
- Половина полученного урона — «серое» здоровье: оно возвращается по 3 в секунду, только пока герой отдыхает напарником.

## Командные приёмы

Смена по обстановке: вошедший герой появляется у цели и бьёт; его следующие удары 2,5 с сильнее в 1,3 раза.

| Приём | Когда нажать Tab | Что делает |
|---|---|---|
| TAG ATTACK | в ударе после лёгкого попадания | удар 18 |
| TAG LAUNCHER | в ударе-подбросе или когда цель в воздухе | удар 14, цель взлетает, герой — за ней |
| DOUBLE IMPACT | в тяжёлом ударе после попадания | бьют оба: 34, отбрасывает |
| TAG COUNTER | в окне после парирования или уклонения | удар 24, окно ответа переходит вошедшему |

Помощь напарника — `[T]`, герой не меняется, перезарядка 6 с:

| Приём | Когда | Что делает |
|---|---|---|
| CROSS ATTACK | цель на земле | напарник пролетает сквозь цель: 16 |
| AIR PARTNER COMBO | цель в воздухе | напарник взлетает и держит её в воздухе: 14 |
| TEAM FINISHER | добивание `[E]`, напарник рядом и готов | напарник бьёт вместе с последним ударом, СВЭГ +10 |

Боссы: командного добивания нет. Если босс «ОТКРЫТ», командный приём бьёт в полтора раза сильнее и один раз за окно продлевает его на 0,6 с (TEAM BREAK).

## Напарник

Сам подходит к врагу рядом с игроком (не к тому, кого бьёт игрок, если есть другой) и бьёт раз в 3–5 с: 7 урона и не насмерть — последний удар за игроком. Упёрся в другого врага — делает рывок. Отскакивает от замахов. Держится спереди и по бокам, не под камерой. `tag.auto_assist` выключает его самостоятельные удары.

## Выбывание

Здоровье активного героя кончилось — он падает, управление переходит напарнику («ВЫБЫЛ»). Через 18 с выбывший возвращается с 30 % здоровья. Выбыли оба — поражение.

## Сохранение

В файл сохранения пишется `tag`: активный герой, стиль каждого, здоровье каждого, настройка напарника (`save_data()` / `load_data()`).

Проверка: `--resolution 1280x720 -- --tagcheck=<папка>` («TAGCHECK ok»); с ключом `--ai` — след поведения напарника.

## Weapon Cancel

Удар можно оборвать сменой стиля после первого попадания. Нельзя: если удар не попал; виды атак `heat`, `finisher` (завершители цепочки), `slam`, `freeze`, приёмы пылесоса и доски; атаки с `extra.no_swap`. Под ударом и в добивании смена не работает.

## Perfect Swap

Смена нажата в окне комбо удара, который попал, — в тот же момент, когда можно продолжать цепочку:

- смена вдвое быстрее, надпись и вспышка;
- следующий удар ×1,35 — до первого попадания, не дольше 2,5 с;
- счётчик цепочки не обнуляется;
- открыто окно особого ответа нового стиля (0,8 с);
- СВЭГ +8; сигнал `flow.swapped(from, to, true)` — для Team Hype.

Ограничения: между Perfect Swap пауза 1,2 с; возврат в стиль, из которого только что пришёл (A → B → A за 4 с), не засчитывается.

Между героями переход идёт через Tag Team: Tab в ударе после попадания — командный приём.

Проверка: `--resolution 1280x720 -- --flowcheck=<папка>` — все 12 переходов, отмена, Perfect Swap, прерывание, быстрые нажатия; «FLOWCHECK ok».

# Team Hype и Team Overdrive (этап 12)

`hype.gd` (`TeamHype`, `game.hype`).

## Team Hype

Общая шкала двух героев, 0–100; на экране — полоса под карточками стилей. Сохраняется.

| Источник | Сколько |
|---|---|
| удар, которого не было среди четырёх последних | 1,6 (по врагу в воздухе ещё +2) |
| точное уклонение / парирование | 6 / 8 |
| Perfect Swap | 7 |
| командный приём по Tab / помощь напарника по T | 9 / 6 |
| Freeze (поток от 2) / Perfect Freeze | 5 / 9 |
| трюк на доске | 5 |
| попадание в такт на гитаре | 1,5 |
| добивание / командное добивание | 10 / +6 |

Повтор одного источника в течение 6 с даёт вдвое меньше, затем вчетверо и так далее; одинаковые удары подряд не считаются. Через 7 с без подпитки шкала тает на 2,5 в секунду. Полная шкала не тает.

## Team Overdrive — `[G]` при полной шкале

Постановка на 3 секунды. Герой в состоянии `"overdrive"`, оба героя неуязвимы, до шести врагов в 9 м обездвижены, камера отъезжает на общий план и обходит команду.

| Доля | Что происходит |
|---|---|
| 0,35 с | вход: напарник появляется с другой стороны толпы, бьют оба (12) |
| 0,95 с | приём стиля активного героя (12–16) |
| 1,55 с | приём стиля напарника (12–16) |
| 2,3 с | общий финал: 40, подброс, стоп-кадр |

Приём зависит от стиля: балон — «ГУЛ БАЛОНА» (удар в землю), водяра — «ЗАЛП» (обливает и замедляет), ТЯГА-812 — «ВОРОНКА» (стягивает врагов в центр), скейт — «ПРОЕЗД», гитара — «СОЛО» (разряды), Breaker — «ВЕРТУШКА» (подбрасывает). Пара стилей героев даёт 36 сочетаний.

Правила:
- шкала тратится целиком;
- нельзя: пока героя бьют, в уклонении, добивании, смене стиля, верхом на пылесосе, пока напарник выбыл (`block()` говорит почему);
- в первые 0,3 с можно отменить уклонением (Shift) — вернётся 60 % шкалы; позже постановка доигрывается;
- во время постановки смена стиля и героя не работает;
- **боссы** не обездвиживаются; за один Overdrive босс теряет не больше 12 % здоровья (18 %, если он «ОТКРЫТ»).

Звук постановки синтезируется в `hype._synth()`: гул, удары по долям и свист к финалу.

Проверка: `--resolution 1280x720 -- --hypecheck=<папка>` — накопление и повторы, запреты, постановка по долям, варианты стилей, отмена, босс, сохранение; «HYPECHECK ok».
