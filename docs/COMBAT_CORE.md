# Ядро боя (этап 04)

Одна боевая система на все шесть стилей. Стиль — это данные (атаки и граф комбо), ядро — код, который ведёт удар
от нажатия до конца. Балон VOZDUH полностью работает на ядре; урон, длительности и окна ударов взяты из прежних таблиц `player.gd` без изменений.

## Файлы

| Файл | Что |
|---|---|
| `attack_data.gd` (`AttackData`, Resource) | одна атака: id, тип, урон, равновесие, дистанция, сектор, радиус, длительность, моменты и окно попадания, окна комбо и отмены, перезарядка, клип, шаг, эффекты, звук |
| `style_data.gd` (`StyleData`, Resource) | стиль: оружие, атаки, граф комбо `links`, Heat-цепочка, атаки после уклонения, буфер, пауза против спама, звуки и цвета; `problems()` проверяет данные |
| `style_vozduh.gd` | таблица стиля «Балон VOZDUH» |
| `styles.gd` (`Styles`) | реестр шести стилей: `Styles.by_id("vozduh")`, `Styles.of("pahan")`; будущие стили объявлены заглушками (`ready = false`) |
| `combat.gd` (`Combat`) | ядро: буфер ввода, фазы атаки, окна, попадания, урон, перезарядки, цель |
| `hit_info.gd` (`HitInfo`) | одно попадание: урон, равновесие, направление, отбрасывание, подброс, оглушение, сила, id атаки и стиля |
| `enemy.gd` → `take_hit_info`, `stagger`, `slow` | приём попадания, равновесие, замедление |
| `combatcheck.gd` | проверка в игре (`--combatcheck`) |

## Путь удара

```
нажатие → буфер (0,3 с) → из стойки: links[""][ввод]  →  атака: замах → попадание → завершение
                                                             │ окно комбо [combo_from, combo_to]: буфер → links[атака][ввод]
                                                             │ отмена перекатом после roll_from (по умолчанию после первого попадания)
                                                             └ recovery: герой свободен; оборванная цепочка → пауза chain_cd
```

- **Буфер ввода.** Нажатие помнится `style.buffer` секунд. Нажал чуть раньше окна — цепочка продолжится; нажал в самом замахе — нет. Раньше любое нажатие за время удара ставило следующий удар в очередь.
- **Окно комбо.** `combo_from … combo_to` атаки. Куда ведёт ввод — граф `links`: `{"vz_light1": {"light": "vz_light2", "heavy": "vz_nail"}}`. Тяжёлые (`heavy`) цепочку не продолжают.
- **Против спама.** После цепочки, которая оборвалась сама, новый лёгкий удар возможен через `chain_cd` (0,15 с). У атаки может быть своя перезарядка `cooldown`.
- **Попадание.** С момента `hits[i]` открыто окно `hit_window`: каждый кадр проверяются дистанция и сектор; цель задевается одним моментом удара один раз (журнал попаданий). `detect = "sweep"` добавляет хитбокс самого оружия: отрезок оружия и путь его конца за кадр против капсулы врага (радиус и высота — хёртбокс), открывается за `hit_lead` до момента удара.
- **Урон.** `Combat.damage_for()`: база × ПЕРЕГРУЗ × `player.dmg_mul` (прокачка). Одна точка для будущих навыков и мастерства.
- **Равновесие.** У обычного врага 60, у босса 200. Атака снимает `stagger`; кончилось — «СБИТ»: обычный враг оглушён на секунду даже в замахе, босс вздрагивает. Через 2 с без ударов восстанавливается. В воздухе, лёжа, в оглушении и в особом приёме босса не снимается.
- **Отклик.** Событие `Feedback` по силе атаки (`power` 0/1/2) или своё (`feedback`), звуки попадания стиля (`hit_sfx`) или атаки (`sfx_hit`), след оружия (`trail_boost`), удар в землю (`slam`), скрежет (`scrape`), падение оружия (`drop`).
- **Сигналы ядра:** `attack_started`, `attack_hit`, `attack_ended` — для HUD, навыков и проверок.

## Как добавить стиль

1. `style_<имя>.gd` с `static func build() -> StyleData`: оружие, `AttackData.make({...})` на каждую атаку, `links`, при необходимости `heat`, `after_dodge`, `roles`.
2. Строка в `Styles._make()`.
3. Клипы стиля — в `clips_*.gd` / `moves_*.gd`; доли `hits`, `step`, `slam` совпадают с ключами клипа.
4. `--combatcheck` и `--animcheck`.

Код ядра менять не нужно, пока стиль укладывается в «атака с моментами попадания». Дистанционные и особые режимы (бутылки, ТЯГА-808) добавляют свои контроллеры рядом с ядром, но урон наносят тем же `HitInfo`.

## Проверка

```bash
tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot --fixed-fps 30 --resolution 1280x720 -- --combatcheck=<папка>
```

В настоящей главе, на боте, клиппере и хейтере: данные шести стилей, клипы атак, урон только в момент попадания, один удар — один раз по каждой цели, цепочка лёгких, четыре ветки «n лёгких → тяжёлый», буфер (слишком рано — нет, чуть раньше окна — да), отмена перекатом (в замахе — нет, после попадания — да), пауза против спама, перезарядка, равновесие, sweep-хитбокс, Heat-цепочка, заряд. Итог — `COMBAT итог: ошибок 0`.
