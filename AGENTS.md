# GOD OF GRIMERKA — правила работы Codex

Основной рабочий проект — Godot-проект в `godot/`. Браузерная версия не должна заменять или откатывать Godot-версию.

Перед каждой новой задачей:

1. Выполнить `git fetch --prune origin`.
2. Проверить `git status --short --branch` и не стирать чужие или пользовательские изменения.
3. Сравнить текущую ветку с `origin/main`.
4. Если рабочее дерево чистое, обновить `main` только через `git pull --ff-only`, затем создать отдельную ветку задачи от `origin/main`.

Во время работы:

- Не коммитить напрямую в `main`.
- Не применять `push --force`, `reset --hard` и другие разрушительные команды.
- Не публиковать релизы без явного разрешения пользователя.
- Не менять браузерную версию вместо Godot-проекта.
- Не коммитить `godot/.godot/` и случайные массовые изменения `.import`.
- Не перезаписывать сцены или скрипты, которые параллельно меняет другой разработчик; при сомнении сначала уточнить область работы.

После изменения:

1. Проверить синтаксис затронутых GDScript-файлов и загрузку Godot-проекта доступным способом.
2. Просмотреть `git diff` и убедиться, что в коммит входят только файлы текущей задачи.
3. Сделать обычный коммит в ветке задачи и отправить её без force-push.
4. Объединять изменения с `main` через Pull Request.

Старую ZIP-копию `C:\god-of-grimerka-main` не удалять и не использовать как источник для отката актуальных механик.
