# «ГОЛДА 67» — журнал багов плейтеста

Ветка `qa/full-playthrough-fixes`. Проверяется только режим «ГОЛДА 67».

**Как играется.** Настоящая игра из главного меню на отдельном тестовом профиле (своя папка `APPDATA`); героем
управляет «игрок клавишами» `godot/scripts/playtest_golda67.gd` — только события ввода (клавиатура, мышь, с ключом
`--pt-pad` — геймпад), положение героя и состояние забега он не меняет, цель и маршрут читает с мини-карты.
**Это не ручной проход человеком:** окном игры через рабочий стол управлять не удалось (запущенная из папки проекта
игра не входит в список приложений, а установленная сборка пишет в настоящее сохранение игрока). Камеру бот не
вращает. Отдельные системы дополнительно закрыты автоматическими проверками (`node tools/checks.cjs golda67 dvor2 podzemka fortuna`),
где герой переносится по точкам, — это отмечено в колонке «Проверка».

Запуск плейтеста:
`APPDATA=<временная папка grimerka-checks> Godot --path godot --resolution 1280x720 -- --playtest-golda67=<папка> --pt-min=13`
