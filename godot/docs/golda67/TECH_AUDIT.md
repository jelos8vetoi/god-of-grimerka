# ГОЛДА 67 — технический аудит

Дата: 2026-11-20. Читан фактический код `godot/` на коммите `05a4ab4` (main). Браузерная версия и старые документы
не использовались. Источник требований — `SPEC.md` (дословное ТЗ владельца).

## 1. Меню: куда вставить «ГОЛДА 67»

### Как устроено сейчас

- Раздела с названием «МИНИ-ИГРЫ» в игре **нет**. Есть экран «ВЫБОР РЕЖИМА» (PLAY) — `ModeSelect.MODES`
  в `scripts/mode_select.gd:17`. В нём пять карточек подряд:

  | № | id | Название |
  |---|---|---|
  | 01 | `story` | STORY MODE |
  | 02 | `training` | TRAINING ARENA |
  | 03 | `race` | VACUUM RACING |
  | 04 | `microloans` | PAHAN MICROLOANS |
  | 05 | `five_nights` | FIVE NIGHTS WITH PAHAN |

- «Мини-играми со своей сценой» код называет только два последних: `main.MINIGAMES` (`main.gd:496`) —
  `microloans` и `five_nights`.
- Выбор карточки: `ModeSelect.activate()` → `menu.open_mode(id)` (`menu.gd:685`, `match` по **id**, не по номеру) →
  экран режима → `menu.launch_minigame(id, opt)` → `main.cinematic_minigame` → `main.start_minigame` (грузит
  `MINIGAMES[id]["scene"]`, ставит `main`, вызывает `begin(continue)`).
- Выход: `main.end_minigame(индекс карточки)` → меню → `menu.open_modes(индекс)`.

### Неясность, которую решает владелец

«Вторым в списке мини-игр» можно прочитать двумя способами:

- **Вариант А (рекомендуется, так и спроектировано ниже):** вторая карточка экрана «ВЫБОР РЕЖИМА» — сразу после
  STORY MODE. Порядок: STORY MODE, **ГОЛДА 67**, TRAINING ARENA, VACUUM RACING, PAHAN MICROLOANS, FIVE NIGHTS.
  Это единственный видимый игроку список, и приквел встаёт рядом с кампанией.
- **Вариант Б:** вторая среди «мини-игр со своей сценой» — после PAHAN MICROLOANS, перед FIVE NIGHTS
  (пятая карточка из шести).

### Что придётся изменить при вставке (вариант А)

1. `ModeSelect.MODES` — новая запись на индекс 1; поле `"no"` у всех следующих сдвинуть (`02`→`03` …). Номер
   хранится строкой в данных, сам не пересчитывается.
2. **Жёсткие индексы карточек** — главный риск, сдвигаются все:
   - `main.gd:571`, `main.gd:578` — `menu.open_modes(2)` (гонки) → 3;
   - `microloans/ml_root.gd:645` — `main.end_minigame(3)` → 4;
   - `five_nights/fn_root.gd:329` — `main.end_minigame(4)` → 5;
   - `menu.gd:229` — `{"training": 1, "race": 2}` (ключ запуска `--menu=`) → 2 и 3;
   - проверки: `modecheck.gd` (165–375), `racecheck.gd:131`, `playtest_race.gd:100`, `mg_uicheck.gd`.
   Правильное решение на этапе кода — убрать числа: функция `ModeSelect.index_of(id)` и вызовы по id. Тогда
   следующая вставка ничего не ломает.
3. `ModeSelect._build_art` — композиция карточки (`match id`): нужна ветка `"golda67"` (своя сценка в SubViewport
   из настоящих моделей: Пахан, madk1d, Миша Минасян, золотые «67»).
4. `ModeSelect._tag` — плашка состояния («ЗАБЕГ 3 · ДВОР», «ПОБЕДИТЕЛЬ 67», «ЗА КАДРОМ»).
5. `menu.open_mode` — ветка `"golda67"` → `_open_golda67()` (ПРОДОЛЖИТЬ / НОВАЯ ИГРА / НАЗАД, как у «Микрозаймов»).
6. `main.MINIGAMES` — запись `golda67` со сценой `res://scenes/golda67/golda67.tscn`.
7. Вёрстка: шаг карточек `_step() = min(164, 560 / N)`; при шести карточках шаг 93 px, масштаб 0,62 — влезает,
   но мельче. Проверить снимками в четырёх размерах окна (`--modecheck`).
8. `main.user_play()` / `tutorial_on()` — добавить ключ будущей проверки `--golda67check`.

### Что проверить в обработчике второго пункта

- клавиши, мышь (hover и клик по зоне карточки), геймпад — выбирается именно «ГОЛДА 67»;
- `activate()` на индексе 1 открывает экран приквела, а не тренировку;
- TRAINING / RACE / MICROLOANS / FIVE NIGHTS по-прежнему открываются со своих новых позиций;
- возврат из каждого режима встаёт на свою карточку;
- `--menu=training|race` открывают правильные карточки.

## 2. Запуск: мини-игра со сценой или `game` в особом режиме

Приквелу нужен настоящий бой кампании (шесть стилей, враги, TagTeam, Duo, Hype). Весь он живёт в `game.gd` и
ждёт вокруг себя `game.player`, `game.buddy`, `game.enemies`, `game.fx`, `game.tag`, `game.hype`, `game.story`.
Поэтому приквел — **не** сцена «с нуля», а образец тренировочной арены:

- `main.start_training` (`main.gd:581`): создаёт обычный `game.gd`, вешает на него `Training`
  (`game.training`), и `Training.begin()` сам ставит `game.mode`, строит мир `world.build("training")`, ставит героя.
- `game.gd` уже уважает этот флаг: `_save()` выходит (`game.gd:278`), `on_kill` → `training.on_kill`
  (без опыта и сюжета), `on_player_dead` → `training.on_dead`, HUD берёт строку у арены.

**Проектное решение:** `Golda67` — контроллер того же вида (`game.golda`), запускается из `main.start_golda67`
через сцену-обёртку `scenes/golda67/golda67.tscn` (требование ТЗ «собственные сцены»). В `game.gd` условия
`training != null` расширяются до «режим со своим контроллером» (одна функция `game.side_mode()`), чтобы не
плодить проверки. Сюжетное сохранение кампании при этом не пишется никогда.

Чего у арены нет и что нужно приквелу: свои локации (не `world.gd` кампании), двери и комнаты, хаб с
взаимодействиями, свой сюжет и диалоги, свои боссы, свой интерфейс наград, видеоплеер.

## 3. Боевая система — что есть и как использовать

| Система | Файл | Как использует приквел | Правки |
|---|---|---|---|
| Шесть стилей | `styles.gd`, `style_*.gd`, `balance.gd` | как есть | не трогать |
| Ядро боя | `combat.gd`, `attack_data.gd`, `style_data.gd` | как есть | точка для фитсов (см. ниже) |
| Набор стилей героя | `player.own_styles` (`player.gd:54`), `set_style` | до босса 1 — только `vozduh`, после — `bottles`, после босса 2 — `tyaga812` | приквел задаёт список; клавиши 1/2/3 идут по нему |
| Бутылки | `style_bottles.gd`: `ammo_max = 6`, `ammo_regen = 3.0` | совпадает с ТЗ | фитсы FORTUNA меняют копию значений забега |
| Смена героя | `game.swap_heroes`, `tagteam.gd` | до первой концовки запрещена; после — как в кампании | запрет через `tag.tag_block()` |
| Напарник | `companion.gd` (`game.buddy`) | до первой концовки madk1d в бою **не участвует** (он в хабе) | нужен режим «напарника нет»: сейчас `game` всегда создаёт buddy |
| Duo | `duo.gd`: `PAIRS` — 9 пар | после первой концовки, как есть | не трогать |
| Team Hype / Overdrive | `hype.gd` (`MAX 100`, `BOSS_CAP 0.12`) | после первой концовки; фаза 4 финального босса | не трогать |
| Perfect Swap | `weaponflow.gd` (`BOOST 1.35`, `BOOST_T 2.5`) | с двух стилей (после босса 1) | фитсы Королевского цепляются за `judge` |
| Потолок усилений | `Balance.MOMENT_CAP = 2.0` в `player.damage_bonus` | фитсы складываются под тем же потолком | отдельный потолок фитсов |
| Добивания | `execution.gd` | как есть | событие для фитсов Миши |
| Враги | `enemy.gd` (`KINDS`, `BOSS_LOOK`), `enemy_ai.gd` (`MOVES`, `TUNE`) | новые враги — новые строки данных с новой моделью | данные берутся из `game.story["BOSS"]` — приквелу нужен свой словарь |
| Боссы | `enemy._setup_boss`, `boss_moves.gd` | своя таблица фаз и приёмов | особые механики арен (турникеты, камеры, копии) — новый код контроллера босса |
| Захват цели, движение, HUD, эффекты, отклик | `lockon.gd`, `player.MOVE`, `hud.gd`, `fx.gd`, `feedback.gd` | как есть | — |
| Обучение | `tutorial.gd` (`main.tutorial_on`) | практика в первом забеге | ключ `"tut"` — в сохранение приквела |
| iPod | `ipod.gd` (`IPod.allowed`) | решить: разрешить в приквеле или нет | вопрос владельцу |

**Фитсы** (усиления забега) ложатся поверх без переписывания: урон уже сходится в одну точку
(`player.damage_bonus(AttackData)`, `combat.damage_for()`), события боя уже есть как сигналы
(`combat.attack_started/ended`, `game.hit_confirmed`, `game.feedback_fired`, журналы TagTeam / WeaponFlow / Hype,
`enemy.take_hit_info`). Модуль фитсов слушает их и держит свои множители в данных забега; исходные `StyleData`
и `AttackData` не изменяются (у `Styles.by_id` результат общий — менять его нельзя, только читать).

**Постоянная прогрессия** («АВТОРИТЕТ РАЙОНА»): у `game` уже есть `player.max_hp`, `player.dmg_mul`,
`_apply_upgrades()` — приквел задаёт их из своего сохранения.

## 4. Враги и модели, которые уже есть

`godot/assets/models`: `pahan`, `madk1d`, `bot`, `clipper`, `hater`, `drey` (босс), оружие `balon`, `bottle`,
`tyaga812`, `skateboard`, `guitar`, `katana`, `staff`, `earpods`. Восемь типов врагов кампании — это три модели
(`bot`, `clipper`, `hater`) с разным цветом и размером. Девять боссов кампании — те же три модели крупнее плюс `drey`.
По ТЗ старых боссов в приквеле использовать нельзя — нужны пять новых моделей.

Клипы всех персонажей строятся кодом (`poses.gd`, `clips_*.gd`) на скелете Mixamo; у новой модели скелет ставит
`tools/rig-horror.py` (шаблон `pahan`), после чего ей доступны все существующие клипы врагов. Уникальные
анимации боссов и сценок — новые клипы в новых файлах `clips_g67_*.gd`.

## 7. Локации

- `world.gd` строит всё кодом: девять оформлений кампании, подъезд `hall` (`_deco_hall`, 4×5×3,2 м) и арену
  `training`. Арена — круг радиуса `ARENA = 15`.
- Подъезд кампании — готовая основа атмосферы хаба, но хаб приквела больше (лестничная клетка в два пролёта,
  лавочка у входа, скрытая дверь) — нужен свой построитель `g67_world.gd`, который ставит модули через
  `MGModels.spawn` / `RaceProps.spawn` (поворот лица `FRONT`, вписывание `FIT`, плоские вещи — `spawn_flat`).
- Двор, гаражи, хрущёвки, лавки, ларёк, машины уже есть моделями в `assets/racing` (см. `ASSET_MANIFEST.md`).

## 8. Звук

- `tools/godot-music.cjs`: таблицы `LOCS` и `BOSSES` — синтез, файлы в git не лежат. Приквелу: наборы
  `loc_g67_hub`, `loc_g67_dvor`, `loc_g67_podzemka`, `loc_g67_lenta`, `loc_g67_ferma`, `loc_g67_backstage`,
  `loc_g67_studio`, боссы `boss_g67_*`, отдельные темы событий (хомяки, казино, аниме).
- `tools/godot-voice.cjs`: говорящий — строка в `VOICED` (код → переменная окружения с id голоса Fish Audio).
  Сейчас: `V`, `M`, `MV`, `B1`, `FN`, `N`, `C1…C4`. Приквелу нужны новые коды и голоса (см. `AUDIO_BIBLE.md`);
  скрипт читает строки из `story.json` и из скриптов данных — добавить чтение данных приквела.
- Правило «говорит кто-то один» (`game._speaking()`, `_hush()`) — использовать в диалогах приквела.
- Шины: Music / SFX / Ambient / Voice, подшины UI, Horror, Phone, IPod. Роликам нужна подшина `TV` → `Voice`/`SFX`
  с фильтром «динамик телевизора».

## 9. Интерфейс и подсказки

- `mg_ui.gd` (`MGUI`) — дизайн-система мини-игр (цвета, шкала текста, `panel`, `stat`, `bar`, `keycap`, `button`,
  `MGUI.audit()`); значки — `mg_icon.gd` (`MGIcon.make`), эмодзи запрещены. На ней строятся: выбор фитса,
  «АВТОРИТЕТ РАЙОНА», карта маршрутов, «АРХИВ ПИЗДЕЦА», магазин ларька, плеер роликов. Новые экраны добавить в
  `mg_uicheck.gd`.
- `mg_hints.gd` (`MGHints.tip(id)`) + `mg_hints_data.gd` — новый словарь `G67`: двери, типы комнат, фитсы,
  артефакты, голда и РЕСПЕКТ, мини-игры событий.
- Боевой HUD — `hud.gd` (`CombatHud`): карточки стилей берутся из `own_styles` — проверить вид с одним и двумя
  стилями (сейчас всегда три).

## 10. Видеоролики

Готового проигрывателя постановочных сцен нет. Близкое: `director.gd` (съёмка трейлера по планам), `intro.gd`
(шторка), `death.gd` (сцена со своей камерой), SubViewport-сценки меню (`mode_select.gd`, `menu_studio.gd` —
экран телевизора шейдером `SCREEN_SHADER`). Нужна одна переиспользуемая система: клип = данные (планы камеры,
действия персонажей, реплики, плашки, звуки, эффекты) → играет в SubViewport → показывается на телевизоре хаба,
на экранах районов или на весь экран (16:9 и 9:16). Подробно — `CINEMATIC_BIBLE.md`.

## 12. Риски

| Риск | Чем грозит | Что делать |
|---|---|---|
| Жёсткие индексы карточек | после вставки режимы открывают чужие экраны и возвращаются не туда | перевести на id до вставки, прогнать `modecheck`, `racecheck`, `microloanscheck`, `fivenightscheck` |
| `game.gd` заточен под кампанию (главы, `story.json`, buddy всегда есть) | правки ради приквела могут сломать кампанию | менять только через `game.side_mode()`; после каждой правки — `node tools/checks.cjs combat modes` |
| Данные боссов читаются из `game.story["BOSS"]` | новых боссов некуда положить | контроллер подмешивает свой словарь в копию `story` своего экземпляра `game`, файл `story.json` не меняется |
| Скелет новых моделей | Tripo отдаёт без скелета или с A-позой | T-поза без авторига, `rig-horror.py`; проверять листом поз |
| Объём: 22 ролика, 5 боссов, 15 мини-событий | срок | ролики — данными одной системы; события — на общих заготовках (ритм, «тапай», барабаны) |
| Вес сборки | десятки новых `.glb` | `glbslim.gd`, текстуры 1024, `compress/mode=2` |
| Мат без цензуры в озвучке | Fish Audio может отказать на отдельных строках | проверить на трёх строках до общей генерации |
| Шесть карточек в меню | мелкий текст на 1280×720 | снимки; при необходимости прокрутка списка |
| Время суток и погода | у `world.gd` свет задаётся темой | своя таблица тем приквела |
