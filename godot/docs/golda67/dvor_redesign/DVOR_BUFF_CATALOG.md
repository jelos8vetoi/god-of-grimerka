Источник существующих записей — `godot/scripts/golda67/g67_data.gd` (`FITS`, `ARTIFACTS`, `KIOSK`).

В данные игры ничего не внесено — это этап реализации.

### Проверка «не бесполезен ли»

| Баф | Когда нужен | Когда не нужен |
|---|---|---|
| ДЕДОВСКАЯ КУРТКА | против группы из 4–5: удары идут сериями | против одиночной элиты — почти не работает |
| БАНКА ИЗ ЛАРЬКА | стиль через уклонения | игрок, который блокирует |
| СКОЛЬЗКИЕ ПОДОШВЫ | вместе с БАНКОЙ ИЗ ЛАРЬКА даёт постоянное усиление | без уклонений мёртв |
| ГАРАЖНЫЙ КЛЮЧ | открывает врагов на добивание — помогает ДОБИВАЛЕ и Платиновому значку | на Мише слаб — и это намеренно |
| ПЕРВЫЙ УДАР | быстро убирает свиту | в долгом бою с боссом — один раз |
| СЕМКИ | для аккуратной игры; +15 за бой — до 90 голды за «боевой» забег | если игрок принимает удары |
| СВОЙ ЧЕЛОВЕК | только если в забеге есть Петрович или Жора | иначе работает лишь в «ШАУРМЕ 67» — режиссёр не выдаёт его, когда новых торговцев нет |
| РАЙОН ПОМНИТ | награждает за события, а не за бои | в «осторожном» забеге без событий даёт ноль |
| ТЁПЛЫЙ ПОДЪЕЗД | перед Мишей — как лишняя шаурма | после передышки бесполезен — не предлагается на позициях 5–6 |

Сборки, которые теперь возможны: **«уклонист»** (БАНКА ИЗ ЛАРЬКА + ПОДОШВЫ + SIM-карта + Кассета 2016), **«ломатель»** (КЛЮЧ + Изолента + Грилзы + ДОБИВАЛА),
**«свой на районе»** (СВОЙ ЧЕЛОВЕК + РАЙОН ПОМНИТ + СЕМКИ + ЦЕПЬ).

## 7. Улучшения

I → II → III. Копия бафа повышает уровень; у Петровича — за голду; жетон улучшения — бесплатно; победа в армрестлинге — «ТЯЖЁЛАЯ РУКА».
Копия бафа на максимуме превращается в 25 голды. Обмен — раз за забег. Артефакты уровней не имеют.
