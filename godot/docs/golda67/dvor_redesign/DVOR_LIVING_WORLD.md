# ДВОР — живой район (проект на одобрение)

Состояние: **проект. В новом районе ничего из этого не встроено.** Основа уже есть в игре с «ДВОРА 1.5» (2026-11-23) — её нужно перенести на новую карту, а не писать заново.

## Что уже есть в коде

| Система | Файл | Что умеет |
|---|---|---|
| Жители | `g67_resident.gd` (`G67Resident`) | расписание, ходьба по точкам, посидеть, убежать от драки, сирена |
| Поведение стоящего жителя | `g67_life.gd` (`G67Life`) | основная поза и другие, взгляд за героем вблизи, реакции |
| Разговоры парами | `g67_duos.gd` (`G67Duos`) | двое говорят, пузыри и голос через `G67Barks` |
| Микрособытия | `g67_yard_life.gd` (`G67YardLife`, `fire(id)`) | прохожие, очередь, окно с криком, снег с крыши, домофон |
| Реплики, надписи | `g67_life_data.gd` (`G67LifeData`) | тексты и разговоры |
| Голуби | `g67_pigeon.gd` | стая, взлёт при приближении |
| Звук | `G67Sound` (29 видов, шаги по `G67Yard.surface_at`), `MusicDirector` | фон, шаги по снегу и асфальту |

## Кто и где в новом районе

Скелеты — существующие `g67_npc_*` со скелетом Пахана. Новых сюжетных персонажей нет.

| Житель | Место (план V5) | Занятие |
|---|---|---|
| бабка | лавка у подъезда дома 67 | сидит, провожает взглядом, комментирует |
| мужик в ушанке | навес со столом | сидит с магнитофоном |
| таксист | у «Жигулей» на улице Облачной | курит, спорит с соседом |
| автомобилист | парковка двора 61–63 | чистит машину от снега |
| школьник | у школы и на стадионе | лепит снеговика, убегает от драки |
| продавец | окно «ШАУРМЫ 67» | торгует, закрывает окно при драке рядом |
| мастер | «МАСТЕРСКАЯ» в ГСК | чинит машину; он же гаражный торговец |
| дворник | тротуар улицы Битной | метёт, ходит туда-обратно |
| двое у гаража | ГСК, третий проезд | спорят (`G67Duos`) |
| прохожие | обе улицы, тропа через пустырь | идут по маршрутам, 3–4 одновременно |
| очередь | «ШАУРМА 67», рынок | 2–3 человека (`G67Poses.QUEUE`) |

Одновременно рядом с игроком — не больше 10–12 жителей; дальние дворы «спят» (думают по очереди, вдали не анимируются — как зрители гонок).

## Микрособытия (декоративные)

Машина буксует в снегу · кто-то выносит мусор · собака лает из-за гаража · голуби у навеса · хлопает дверь подъезда · окно: «Петя, домой!» ·
сигнализация вдалеке · «буханка» проезжает по улице · снег падает с козырька · дворник скребёт лопатой.
Часть уже есть в `G67YardLife`; новые — машина в сугробе, «буханка», собака (собаки-модели нет — только звук).

## Реакция на драку

Жители в 15 м убегают в подъезды (`_start_flee` уже есть), дальние смотрят; продавец закрывает окно; у задетой машины — сигнализация;
голуби взлетают; из окна кричат. После боя возвращаются через 20–30 с.

## Звук

Есть: скрип снега, шаги по разным поверхностям, фон района. Добавить: хлопки подъездных дверей, лай, далёкая сигнализация, гул трансформаторного шкафа,
шум гаражей (болгарка, радио), ветер между башнями. Музыка — через `MusicDirector`, новых режимов не нужно.

## Чего нет и что нужно

- Моделей собаки, велосипеда, лопаты, лотка торговца нет.
- Реплики для новых жителей (таксист, автомобилист, мастер, дворник) — нужны тексты владельца; голоса — пресеты Voice Studio Pro.
- Производительность: район в шесть раз больше; нужен замер (`--g67-perfzones`) после сборки в игре.
