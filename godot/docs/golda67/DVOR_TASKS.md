# ГОЛДА 67 — район ДВОР: список оставшихся задач

Составлен 2026-11-20 по требованию владельца («дальнейшая доработка района ДВОР»). Задачи идут по порядку
приоритета; к ПОДЗЕМКЕ не переходим, пока ДВОР не согласован. После каждой крупной задачи — проверка в игре
(перемещение, бой, переходы, сохранение) и существующие проверки `node tools/checks.cjs`.

Статусы: **сделано** / **в работе** / **ждёт** / **ждёт модель** / **ждёт решения владельца**.

## Приоритет 1 — то, что ломает ощущение настоящего места

| № | Задача | Что именно | Статус |
|---|---|---|---|
| 1.1 | Границы боя без невидимых стен | Сейчас зону боя держат невидимые стенки с золотым пунктиром. Сделать: на время боя зону огораживают видимые турнирные ограждения; после победы они убираются, и по двору можно свободно ходить. Двери выбора стоят у входов в следующие зоны — до них надо дойти | **сделано**: на бой зону огораживают турнирные ограждения, после победы их убирают, двор свободен, ворота стоят у входов в следующие зоны |
| 1.2 | Арена Миши: оформление коробки | Настоящие борта и калитка, мачты прожекторов, трибуна зрителей, трон и машина Миши, растяжки турнира, лёд или утоптанный снег на площадке | **частично**: борта, калитка, мачты, трон, машина Миши, лёд с разметкой — стоят; осталось: трибуна, растяжки, реакция зрителей |
| 1.3 | Постановка выхода Миши | Сейчас камера обходит стоящего босса. Сделать: он сидит на троне, встаёт, идёт по ковру, цепь цепляется — «контроль пространства», зрители реагируют, свет прожекторов включается по очереди | ждёт: клипы «сидит / встаёт / проход», модель трона |
| 1.4 | Бой Миши: свои механики | Захват (уклонение вбок, блок не спасает), защитная стойка-контратака (не бить — бить после), зацеп цепи за турник и борт (окно «ОТКРЫТ»), разные связки по фазам; у каждого приёма — метка на земле той же формы, замах не короче 0,4 с, окно для ответа игрока | ждёт |
