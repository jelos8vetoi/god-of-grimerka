## 2. Комната

Арена 14–22 м (у кампании круг радиуса 15 — `world.ARENA`; приквел использует прямоугольные комнаты со стенами
из модулей). Цикл: вход → двери закрываются → 2–3 волны → награда появляется в центре → открываются 2–3 двери
с **значком следующей комнаты и значком награды** над каждой.

Восемь типов (ТЗ, раздел 9) — больше не добавляется:

| Тип | Что внутри | Награда | Длительность |
|---|---|---|---|
| BATTLE | 2–3 волны обычных врагов | голда, иногда фитс | 1,5–2 мин |
| ELITE | элитный враг со свитой | редкий фитс или артефакт + голда | 2–3 мин |
| FIT | без боя: три фитса на выбор | фитс | 20 с |
| STORAGE | кладовка: один артефакт из двух | артефакт | 20 с |
| KIOSK | ларёк: 3–4 товара за голду забега | лечение, фитс, улучшение фитса, боезапас | 30 с |
| BREAK | лавка и чайник: лечение (варианты — из «АВТОРИТЕТА») | здоровье | 20 с |
| RANDOM EVENT | событие (раздел 5) | по событию | 0,5–3 мин |
| BOSS | арена района | стиль / сюжет, РЕСПЕКТ | 3–5 мин |

## 3. Маршрут района (линия 1)

```
 вход ── B ──┬── B / FIT ──┬── ELITE / STORAGE ──┬── KIOSK / EVENT ──┬── BREAK ── BOSS
             └── EVENT ────┘                     └── B ──────────────┘
 позиция:  1        2                3                    4               5        6
```

- Шесть позиций до босса; на позициях 2–4 игрок выбирает из 2–3 дверей.
- Позиция 1 — всегда BATTLE; позиция 5 — всегда BREAK (перед боссом); позиция 6 — BOSS.
- В районе минимум три боя и не больше четырёх; один гарантированный FIT; KIOSK — не раньше позиции 3.
- Сложность: район задаёт состав врагов, позиция — число и волны (`EnemyAI.TUNE` и `game.diff_hp` остаются
  ручками сложности).

## 4. Гарантии: сюжет нельзя потерять

Случайность выбирает **вид и порядок** комнат, но не может убрать обязательное. Механизм один — «очередь
обязательного»:

1. В `meta` сохранения лежит список обязательных сцен с состояниями `не видел` / `видел`.
2. При построении маршрута района генератор сначала расставляет обязательные сцены, положенные этому району и
   ещё не увиденные, и только потом заполняет остальное случайно.
3. Обязательная сцена занимает дверь, которую **нельзя не выбрать**: если на позиции стоит несданное
   обязательное событие, оно есть среди дверей; если игрок прошёл мимо дважды, на следующей позиции дверь одна.
4. Гибель до сцены ничего не теряет: в следующем забеге она снова в очереди.
5. Перед боссом Ботофермы (последняя точка до первой концовки) генератор проверяет очередь линии 1: всё
   несданное выстраивается в цепочку комнат до босса. До концовки нельзя дойти, не увидев четыре события и
   встречи КРОТА 1–7.
6. Увиденное можно пересмотреть в «АРХИВЕ ПИЗДЕЦА».

## 6. Линия 2 — «ЗА КАДРОМ»

Не забег по четырём районам заново, а **четыре главы с фиксированным каркасом**: в главе 5 комнат, из них 2–3
боевые выбираются дверями, сюжетные стоят на месте. Гибель возвращает в хаб; пройденные главы не повторяются
(прогресс главы — в `meta`). Командная игра: Tab, T, G, девять пар Duo — как в кампании.

| Глава | Каркас комнат |
|---|---|
| 1 ЗАКУЛИСЬЕ | вход с изнанки двора → бой → запись 1 → бой/элита → запись 2 (STORY03) → КРОТ 8 → запись 3 |
| 2 МОНТАЖНАЯ | бой → MOGGING CHALLENGE 67 → бой/ларёк → ANIME ROOM 67 → исходный файл |
| 3 ЦЕНТР НАКРУТКИ | бой → сервер 1 → бой → сервер 2 (STORY04) → элита → сервер 3 |
| 4 ПОСЛЕДНИЙ ЭФИР | фальшивые рейтинги → перекрашенные декорации → испытание на командную работу → КРОТ 10 → видеозапись → BREAK → WHYOUSOLONELY |

«Испытание на командную работу»: две плиты и два рубильника, которые нужно держать разными героями, и бой, где
щит врага снимается только командным приёмом.

## 7. Экономика забега и прогрессия

- **Голда забега** — с врагов и комнат; тратится в KIOSK; сгорает при гибели и в конце забега.
- **РЕСПЕКТ** — постоянный: за комнату 1–3, за элиту 5, за босса 20 (первая победа — 40), за событие 5.
  Не теряется никогда.
- Стоимость всего дерева «АВТОРИТЕТ РАЙОНА» ≈ РЕСПЕКТ, который игрок получает за нормальное прохождение обеих
  линий (≈ 600). Гринда нет: первая концовка проходима без единого улучшения, улучшения — страховка.

| Ветка | Уровней | Эффект за уровень |
|---|---|---|
| Максимальное здоровье | 5 | +10 |
| Базовый урон | 5 | +4 % |
| Восстановление ресурсов | 3 | перезарядки и боезапас −8 % |
| Варианты лечения | 2 | в BREAK +1 вариант |
| Шанс редких фитсов | 3 | +6 % |
| Повторный выбор | 2 | +1 перевыбор за забег |
| Слоты артефактов | 2 | 3 → 4 → 5 |
| Стартовая голда | 3 | +30 |
| Открытие маршрутов | 3 | старт с района 2 / 3 / 4 |

### Фитсы
Четыре семейства (ТЗ, раздел 10), по 6 фитсов: 4 обычных, 1 редкий, 1 легендарный; каждый улучшается дважды.
Три утверждённые синергии — отдельные «двойные» фитсы, выпадают при наличии обоих семейств. Ограничители:
повтор эффекта не запускает новый повтор; общий множитель урона от фитсов ≤ ×2,0 поверх `Balance.MOMENT_CAP`;
каждый фитс показывает срабатывание значком у полоски здоровья. Семейства Бустеренко «Team Hype» и часть
Королевского «Perfect Swap» в линии 1 предлагаются только когда механика доступна (нужны два стиля; Hype — после
концовки 1), чтобы не выдавать бесполезное.

### Артефакты
18 предметов: десять из примеров ТЗ, три событийных (ЧЕСНОЧНАЯ АУРА, ХОМЯЧЬЯ АУРА, ОШЕЙНИК 67) и пять для
линии 2 (открываются первой концовкой). Событийные после получения остаются в коллекции навсегда и могут быть
взяты в слот перед забегом.

## 8. Смерть и повтор

Сцена гибели — существующая `DeathSeq`. После неё — короткая сводка «почему»: кто и чем добил, сколько урона от
какого врага, какой фитс не сработал ни разу; кнопки «В ПОДЪЕЗД» и «ЕЩЁ РАЗ». Сюжет, ролики, РЕСПЕКТ и
улучшения сохранены.

## 9. Вертикальный срез (под партию P0)

Хаб «ПОДЪЕЗД» (без скрытой двери в работе) → район ДВОР целиком: шесть позиций, враги «Шестёрка», «Семечник»,
элита «Смотрящий», КРОТ 1, dj flürr, фитсы семейства Миши, босс Миша Минасян, NEWS01 и AD01, открытие Водяры.
Этого достаточно, чтобы проверить весь цикл: меню → хаб → забег → двери → награды → босс → возвращение.

## Как реализовано во дворе (2026-11-22)

Один двор без комнат. Шесть позиций: бой у подъезда; бой / баф / короткое событие; элита / кладовка / «ТРЯПКИ»; ларёк / событие / бой; передышка; босс. Варианты строит `Golda67.route_options` по пройденному в забеге и `meta["must"]`: боёв 2–3, выбор бафа к четвёртой позиции, обязательное «ТРЯПКИ» нельзя обойти. Окно «ШАУРМА 67» торгует с третьей позиции; «ДВОЙНАЯ» и «С СОБОЙ» — только когда ларёк выбран этапом (первая шаурма тогда бесплатна).

## Как реализовано во дворе (обновлено 2026-11-22)

- **Шесть позиций:** 1 бой у подъезда; 2 бой / баф / короткое событие; 3 элита / кладовка / «ТРЯПКИ»; 4 ларёк / событие / бой; 5 передышка; 6 босс. Варианты строит `Golda67.route_options` по пройденному в забеге и `meta["must"]`.
- **Правила генератора:** боёв на позициях 1–4 — два или три (отличие от плана, где боёв было больше), к четвёртой позиции обязательно есть выбор бафа, пока «ТРЯПКИ» не увидены — они обязательны (на позиции 3 или единственный вариант на 4), короткого события на позиции 2 тогда нет.
- **Ларёк:** окно «ШАУРМА 67» торгует после второй позиции; «ДВОЙНАЯ» и «С СОБОЙ» — только когда ЛАРЁК выбран этапом (первая шаурма тогда бесплатна).
- **Награды:** монеты с врагов и горка за зачистку, свёрток шаурмы за зачистку (бой +25, элита +40), после элиты — вешалка с редким бафом.
- **Миша:** 2600 здоровья, броня 0,7, урон 7; антракт на каждой смене фазы — стойка, неуязвим, вбегает свита (фаза 2 — три Шестёрки, фаза 3 — ещё Семечник), зрители бросают шаурму. Бой с боссом у бота ≈ 2 минуты (в плане 3–5 минут).
- **Враги:** одновременно живых не больше пяти, урон рядовых ×0,6, входят из точек за укрытиями через проёмы в ограждении.
