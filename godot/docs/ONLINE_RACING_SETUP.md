# Как сыграть в сетевую гонку с друзьями

VACUUM RACING → ONLINE RACE. Один из вас **хост**: он создаёт лобби, его компьютер считает всю гонку.
Остальные **подключаются** к нему по IP. Сервера в интернете у игры нет — соединение прямое, от друга к хосту.

## Хост: создать лобби

1. ONLINE RACE → **CREATE LOBBY**.
2. Название, своё имя, сколько игроков (2–8), трасса, круги, пароль (можно пусто). «Приватное» — лобби
   не видно в списке локальной сети, войти можно только по IP.
3. **СОЗДАТЬ.** В лобби вверху написано, что сказать друзьям: IP этого компьютера в домашней сети и порт.
4. Когда все нажали READY — **START RACE** (нужно минимум 2 участника).

## Друг: подключиться

1. ONLINE RACE → **JOIN LOBBY**.
2. В одной сети (дома, по Wi-Fi) лобби само появится в списке — нажми на него.
3. Через интернет — введи **IP хоста** и **порт** (по умолчанию `24710`), имя, пароль, если есть. **JOIN**.
4. В лобби выбери гонщика и нажми **READY**.

Если не вышло, игра скажет почему: хост не отвечает, неверный пароль, лобби заполнено, разные версии игры.
Попробовать снова можно сразу. Версии у всех должны быть одинаковые — обновитесь через лаунчер.

## Порт и почему UDP

Игра использует **UDP-порт 24710** (поиск лобби в локальной сети — UDP 24711).

UDP, а не TCP — потому что гонке важнее свежие данные, чем все данные. Положение гонщиков приходит
20 раз в секунду. Если один пакет потерялся, через 50 мс придёт новый, и ждать старый незачем.
TCP заставил бы всех ждать повтора потерянного пакета, и гонщики дёргались бы.
Важные сообщения (старт, предметы, финиш, результаты) игра всё равно доставляет надёжно — поверх UDP (ENet).

## Через интернет: проброс порта у хоста

Друзья подключаются к **публичному IP** хоста. Роутер хоста по умолчанию никого внутрь не пускает, поэтому
хост открывает порт:

1. Узнай IP своего компьютера в домашней сети — его показывает лобби (например, `192.168.1.20`).
2. Зайди в настройки роутера (обычно `192.168.0.1` или `192.168.1.1`), раздел «Переадресация портов» /
   «Port Forwarding» / «Виртуальные серверы».
3. Создай правило: протокол **UDP**, внешний порт **24710**, внутренний порт **24710**, адрес — IP твоего
   компьютера из шага 1.
4. В брандмауэре Windows разреши игре входящие подключения. Windows спросит сам при первом создании
   лобби — нажми «Разрешить».
5. Свой публичный IP можно узнать, например, на сайте 2ip.ru или по запросу «мой ip» в поисковике.
   Его и порт `24710` скажи друзьям.

### Почему может не работать

- **CGNAT** — многие провайдеры (особенно мобильные) дают одному внешнему IP сразу много абонентов.
  Тогда проброс порта невозможен: адрес в настройках роутера (WAN) не совпадает с тем, что показывает
  2ip.ru. Выход — попросить у провайдера «белый» (публичный) IP, хостом быть тому, у кого он есть,
  или общая виртуальная сеть (Radmin VPN, ZeroTier, Tailscale): тогда подключайтесь по её адресу.
- **Строгий NAT / корпоративная сеть** — UDP может быть закрыт вовсе.
- Прямое подключение ENet **не обещает работать через любой роутер без настройки** — так устроены
  домашние сети. Сервер-посредник (relay), который обходит это без проброса, в игре пока не подключён:
  для него нужен выбранный сервис. Код готов к нему — см. «Транспорт» в `ONLINE_RACING.md`.

IPv6: если у хоста и друзей есть IPv6, можно ввести IPv6-адрес хоста — проброс портов тогда часто не нужен,
но брандмауэр роутера всё равно должен пропускать UDP 24710.

## Проверить на двух компьютерах дома

1. Оба компьютера в одной сети (один роутер).
2. На первом: CREATE LOBBY → СОЗДАТЬ. Разрешить доступ в брандмауэре.
3. На втором: JOIN LOBBY — лобби появится в списке. Если нет — введи IP из лобби первого и порт 24710.
4. На втором — READY, на первом — START RACE.

На одном компьютере тоже можно: запусти игру дважды, во второй — JOIN по адресу `127.0.0.1`.
