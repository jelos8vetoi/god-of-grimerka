# Сетевой протокол VACUUM RACING

Godot High-Level Multiplayer поверх `ENetMultiplayerPeer` (UDP). Все RPC — в узле `/root/Main/RaceNet`
(`race_net.gd`). Хост — id 1, слушающий сервер.

- Протокол: `RaceNet.PROTO = 2`.
- Версия игры — коммит сборки (`data/build.json`, поле `sha`). При несовпадении протокола или версии хост
  отказывает и отключает клиента с понятной причиной.

## Каналы

| Канал | Режим | Что |
|---|---|---|
| 0 `CH_EVENTS` | reliable | лобби, приветствие, старт, события гонки, ловушки, коробки, результаты |
| 1 `CH_SNAP` | unreliable_ordered | снимки хоста, 20 в секунду |
| 2 `CH_INPUT` | unreliable_ordered | ввод клиентов, 30 в секунду |

Снимки и ввод не стоят в очереди за надёжными сообщениями. Потерянный снимок не ждут — придёт следующий.

Таймаут связи — 20–40 с (`TIMEOUT_MIN_MS`, `TIMEOUT_MAX_MS`, ставится каждому пиру при подключении),
а не 5 с ENet по умолчанию: пока трасса строится, кадр на слабом компьютере идёт несколько секунд,
и при восьми игроках короткий таймаут рвал связь посреди загрузки. Обычный выход (закрыл лобби,
«ВЫЙТИ») приходит сразу — таймаут ждёт только пропавший без слова компьютер.

## Клиент → хост

Хост принимает только эти пять сообщений, и каждое проверяет.

| RPC | Аргументы | Когда принимается |
|---|---|---|
| `c_hello` | proto: int, build: String, name: String, pass_hash: String | один раз, в лобби; типы, протокол, версия, места, пароль |
| `c_ready` | on: bool | в лобби |
| `c_pick` | rider: String | в лобби; только id из `RaceVisual.RIDERS` |
| `c_loaded` | — | пока хост ждёт загрузки трассы |
| `c_input` | PackedByteArray(7) | во время гонки; только для своего гонщика, не после финиша |

`c_input` — `RaceInput.pack()` (4 байта), номер ввода `u16` и счётчик нажатий прыжка `u8` (всего 7 байт):
- байт 0 — газ 0–255;
- байт 1 — тормоз;
- байт 2 — руль 0–254 (127 — прямо);
- байт 3 — флаги: занос 1, турбо 2, нажатие прыжка 4, предмет 8, назад 16, удержание прыжка 32.

Хост распаковывает ввод, прогоняет через `sanitize()` (пределы) и сохраняет как намерение гонщика. Одноразовые
нажатия ожидают шага физики. Клиент сразу отправляет фронт прыжка и повторяет накопительный счётчик в последующих пакетах. Хост обрабатывает каждый новый фронт один раз, до двух в очереди.

Клиент **не** сообщает позицию, круги, время, предметы, ускорения, победу. Всё это хост считает сам.

## Хост → клиенты

Клиент принимает их только от id 1 (`_from_host`) и проверяет типы.

| RPC | Аргументы |
|---|---|
| `h_welcome` | твой id |
| `h_reject` | причина (строка) — затем отключение |
| `h_lobby` | лобби: `{room, host_name, max, track, laps, private, has_pass, state, port, players: [{id, name, rider, ready, ping, host}]}` |
| `h_load` | конфигурация гонки: `{mode: "online", track, laps, seed, riders: [{id, name, peer}]}` — трасса только из `RaceData.TRACKS` |
| `h_snap` | снимок (ниже) |
| `h_ev` | slot, вид события, значение — эффекты и HUD: предметы, попадания, круги, финиш, возврат, отключение |
| `h_hazard` / `h_hazard_end` | ловушка (мыло, пыль): id, вид, место, радиус / убрана |
| `h_box` | коробка предмета: номер, видна ли |
| `h_results` | `[[slot, время, лучший круг, оценка «~», вышел]]` |
| `h_lobby_back` | все снова в лобби |

### Снимок `h_snap`

Заголовок, 14 байт:
- `u32` номер шага хоста;
- `f32` время гонки;
- `u8` состояние (`wait / intro / countdown / race / done / results`);
- `f32` время в состоянии;
- `u8` число гонщиков.

На гонщика 41 байт:

| Смещение | Тип | Поле |
|---|---|---|
| 0 | f32 ×3 | положение |
| 12 | f16 | нос (heading) |
| 14 | f16 | скорость |
| 16 | u8 | флаги: занос, ускорение, в воздухе, разворот, фильтр, турбо, финишировал, вышел |
| 17 | u8 | уровень заноса (2 бита), сторона (бит 2), воздушный прыжок использован (бит 3) |
| 18 | u8 | заряд турбо |
| 19 | u8 | предмет (0 — нет, иначе номер в `RaceData.ITEM_IDS` + 1) |
| 20 | u8 | круг |
| 21 | u8 | следующая контрольная точка |
| 22 | u8 | место |
| 23 | f16 | направление движения |
| 25 | f16 | время в воздухе |
| 27 | u16 | номер последнего учтённого ввода этого гонщика (клиент сверяет по нему предсказание) |
| 29 | f16 ×2 | оставшаяся скорость отскока, X/Z |
| 33 | f16 | угловая скорость от удара |
| 35 | f16 | оставшееся время восстановления тяги |
| 37 | f16 | вертикальная скорость |
| 39 | f16 | оставшийся кулдаун двойного прыжка |

8 гонщиков — 342 байта, при 20 снимках в секунду ≈ 6,7 КиБ/с на клиента.

## Последовательность

1. Клиент соединяется, шлёт `c_hello`. Хост отвечает `h_welcome` и всем рассылает `h_lobby`.
2. Клиенты выбирают гонщика (`c_pick`) и READY (`c_ready`).
3. Хост жмёт START (можно при ≥ 2 участниках и READY у всех).
4. Хост рассылает `h_load`. Каждый строит трассу и шлёт `c_loaded`. Не загрузился за 60 с — отключается.
5. Все загрузились — хост ведёт облёт, отсчёт, гонку. Клиенты видят их по `h_snap`: свой гонщик начинает
   ехать, только когда хост сказал «race».
6. Финиш подтверждает хост, результаты — `h_results` (время — по часам хоста).
7. «ВСЕ В ЛОББИ» — `h_lobby_back`, лобби снова открыто.

Отключение:
- **Клиент.** Хост помечает его гонщика «вышел» (`peer_left`), убирает его с трассы и из мест, гонка идёт.
- **Хост.** У клиентов `server_disconnected`: соединение закрывается, игра офлайн, экран ONLINE RACE говорит
  почему.

## Защита (клиент — недоверенная сторона)

- **Отправитель.** Проверяется у каждого сообщения: хост принимает `c_*` только от зарегистрированных
  клиентов, клиент принимает `h_*` только от id 1. «Хостовые» RPC с клиента отвергает сам Godot
  (`@rpc("authority")`).
- **Типы и пределы.** Проверяются у каждого аргумента; ввод — ровно 6 байт и `sanitize()`; имя — до
  16 печатных символов; гонщик и трасса — только по известным id. Путей к файлам, сценам и ресурсам
  сообщения не несут и не принимают.
- **Состояние.** READY и выбор гонщика — только в лобби; загрузка — только во время загрузки; ввод — только
  в гонке, для своего гонщика и не после финиша.
- **Частота.** На каждый вид сообщения свой предел в секунду (`RaceNet.LIMITS`, ввод — 90), лишнее
  отбрасывается. Не представился за 5 с — отключение.
- **Предметы.** Подбор, какой выпал (случайность хоста), использование, попадания и конец эффекта решает
  только хост. Повтор и подделка ничего не дают: в руках только то, что выдал хост.
- **Выход.** Выход из сети закрывает `MultiplayerPeer` и ставит `OfflineMultiplayerPeer`; узел RaceNet
  удаляется, кампания про сеть не знает.
