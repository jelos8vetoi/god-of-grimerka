# Интерфейс мини-игр: дизайн-система и проверка вёрстки

Одна система на «ПАХАН НАБРАЛ МИКРОЗАЙМОВ», пять подработок и «5 НОЧЕЙ С ПАХАНОМ»: `scripts/mg_ui.gd` (`MGUI`) и
`scripts/mg_icon.gd` (`MGIcon`). Цель — текст занимает ровно столько места, сколько нужно; у каждого уровня свой
размер и вес; ничего не налезает и не обрезается; 3D-сцена и персонажи остаются видны.

## Что было не так

- Весь текст одним тяжёлым шрифтом и одним-двумя размерами: заголовок, значение и подпись спорили друг с другом.
- Экраны собраны абсолютными координатами под 1600×900: на 21:9 и 16:10 — пустые поля или наложения.
- Панели на пол-экрана закрывали комнату и Пахана; описание печаталось у каждого пункта сразу.
- Эмодзи из системного шрифта вместо значков (цветные, разного веса), символы «☎ ✕ ⚠» в тексте.
- «₽» и «%» уезжали на новую строку отдельно от числа; местами латиница вперемешку с русским (TRUST / PRESSURE,
  NEW GAME / НАЗАД в одном списке).
- В «5 ночах» карта камер и подсказка лежали поверх картинки камеры, подсказки будки — четыре строки текста.

## Шкала текста (экран 1600×900; проект растягивается `canvas_items` / `expand`)

| Уровень | Стиль `MGUI.label(…, стиль)` | Размер | Шрифт |
|---|---|---|---|
| Заголовок экрана | `h1` | 34 | антиква (Bodoni / Georgia, 900) |
| Заголовок панели, выбранный раздел | `h2` | 22 | антиква |
| Главный показатель (деньги, долг) | `num_l` | 30 | антиква |
| Показатель | `num` | 20 | антиква |
| Основной текст | `body`, `body_b` | 16 | гротеск (Segoe UI 600 / 800) |
| Описание, вторичное | `small` | 14 | гротеск |
| Подписи, метки | `micro`, `caps` | 12 | гротеск / Russo One |
| Кнопки, короткие подписи | `btn`, `caps_m` | 14 | Russo One |
| Пульт, таймеры, техническое | `mono_s` 12 · `mono` 14 · `mono_m` 18 · `mono_l` 20 | | Consolas |
| Часы и заголовки «5 ночей» | `caps_l` 22 · `caps_h` 38 | | Russo One |
| Заставки (12:00 AM, ПАХАН УМЕР) | `caps_xl` | 60 | Russo One |

Russo One — только короткие подписи, кнопки и часы; длинный текст им не набирается. Цвета: `INK`, `PANEL`,
`PANEL_SOFT`, `LINE`, `PAPER`, `PAPER_DIM`, `TEXT`, `TEXT_2`, `TEXT_3`, `RED` (акцент и опасность — только по делу),
`GOOD`, `WARN`, `GOLD`. Отступы: `S1…S5` = 4 / 8 / 12 / 16 / 24.

## Кирпичи

- `MGUI.label(текст, стиль, цвет, ширина_переноса)`, `label_3d` (с обводкой — поверх сцены), `style_label`.
- `MGUI.panel(soft, accent, pad)` — тёмная панель с тонкой рамкой; `accent` — цветная полоса слева (статус).
- `vbox / hbox / spacer / vsep / hsep`, `stat(подпись, значение)`, `bar / set_bar`, `chip`.
- `keycap("Enter")` и `hints([["W/S", "выбор"], …])` — подсказки управления плашками клавиш, одной строкой.
- `button(текст)` и `theme()` — кнопки с состояниями (обычная, наведение, нажата, фокус, недоступна).
- `rub(1234567)` → «1 234 567 ₽» с неразрывными пробелами; `nb(текст)` — «₽», «%», «дн.» не отрываются от числа.
- `MGIcon.make(id, размер, цвет)` — свои векторные значки, рисуются кодом в одном стиле: broom wrench box sliders
  crate doc map sofa bag cart star shop phone warn clock coin trophy mail back crown worker tool moon check lock plus
  bolt diamond heart sun search call camera door power fan lure cross hangup. Новый значок — ветка в `_draw_icon`.

Правила: экран собирать контейнерами (HBox / VBox / Grid / PanelContainer), координаты — только для привязки
панели к краю; описание показывать у выбранного пункта, а не у всех; подсказка клавиш — плашки, не предложение;
всплывающее и временное помечать `set_meta("audit_skip", true)`; намеренную обрезку с многоточием — `audit_clip`;
окно поверх остального (подтверждение, ящик, пауза) — `audit_modal`.

## «Микрозаймы»

- Сверху одна тонкая строка показателей: день и фаза, деньги, общий долг (цифры доезжают, изменение — рядом на пару
  секунд), ближайший платёж (срочный пульсирует), стресс, действия, уровень и опыт. Правая половина экрана —
  комнате и Пахану.
- Раздел — панель слева: `MLUI.open(заголовок, строки, пункты, _, режим)`. `"list"` — компактный список (значок,
  название, значение справа), `"cards"` — карточки с 3D-превью для сравнения (подработки, магазин, бизнес),
  `"grid"` — сетка ячеек (вещи). Описание, причина недоступности и что сделает Enter — только у выбранного, внизу.
- Карта долгов и дерево развития — панель во всю ширину: карта / дерево слева, подробности выбранного справа,
  клавиши внизу. Уведомления на таких экранах идут строкой в шапке (`make_toast_slot`), а не карточками поверх кнопок.
- Звонок коллектора — одна колонка по центру: кто звонит, долг, срок и время; реплика на «бумаге», три шкалы
  (ДОВЕРИЕ, ДАВЛЕНИЕ, ОБЕЩАНО НА ЗАВТРА) с числами; шесть ответов строками с плашками клавиш; ящик стола — отдельное
  окно поверх. Пока идёт звонок или подработка, строка показателей и уведомления убраны.
- Подработки: слева плашка «название · цель · прогресс», справа «таймер · счёт · серия», внизу плашки клавиш и одна
  строка подсказки по ходу. Итог — панель по центру: звёзды, оценка, три строки разбора.

## «5 ночей»

Характер — старый охранный пульт: моноширинный текст, Russo One только в часах и коротких заголовках.

- Будка: часы справа сверху, энергия с нагрузкой слева снизу, на первой ночи — плашки клавиш справа снизу. Звонок —
  узкая плашка снизу по центру («F — сбросить»), тревога MOD — строка сверху на 3,5 с, мысли Пахана — строка ниже
  середины. Всё временное гаснет само.
- Планшет камер: картинка крупная и чистая (16:9, больше половины экрана); название камеры и «НОЧЬ · время · REC» —
  над ней; карта камер, пинг сервера, приманка, клавиши и энергия — в боковой панели справа. «Нет сигнала» — по
  центру картинки (её в этот момент всё равно нет).
- Терминал: список на тёмной панели слева, пояснение выбранного — справа, клавиши — внизу. Все пункты по-русски:
  НОВАЯ ИГРА, ПРОДОЛЖИТЬ, ВЫБОР НОЧИ, СВОЯ НОЧЬ, АРХИВ, НАСТРОЙКИ, В МЕНЮ РЕЖИМОВ.
- Пауза, гибель, 6 AM — колонка по центру; кнопки берут фокус (стрелки и Enter), HUD будки под карточкой скрыт.

## Проверка: `--uicheck`

```bash
$G --path godot --resolution 1600x900 -- --uicheck=<папка>
$G --path godot --resolution 1600x900 -- --uicheck=<папка> --ui-only=ml|jobs|fn|long --ui-sizes=1600x900,1280x720
```

`scripts/mg_uicheck.gd` обходит 62 экрана обеих мини-игр (утро, событие, день, подработки, займы, карта долгов и
платёж, магазин, вещи, бизнес, дерево, ЛЕГЕНДА РАЙОНА, подтверждение, пауза, уведомления, вечер, звонок, ящик стола,
концовка; HUD и итог пяти подработок; терминал и восемь его разделов, заставка ночи, будка, звонок, камеры, сломанная
камера, пауза, генератор, гибель, 6 AM) в шести размерах окна: 1600×900, 1280×720, 1920×1080, 2560×1440 (16:9),
1440×900 (16:10), 1680×720 (21:9). На каждом — `MGUI.audit(узел, видимая_область)`:

- «за экраном» — надпись или кнопка вышла за видимую область;
- «за панелью» — вышла за свою панель;
- «наложение» — две надписи пересеклись (сравнивается область, где правда есть буквы, с учётом прокрутки и обрезки);
- «обрезан текст» — не поместился (clip, предел строк, высота).

Раздел «длинные тексты» (`--ui-only=long`) открывает те же экраны с нарочно длинными названиями, описаниями,
метками и суммами в миллионы. Ещё проверяется: клавиши и мышь (выбор, наведение, клик по карте камер), фокус кнопок
паузы, безопасный ответ по умолчанию в подтверждении, картинка камеры не перекрыта, сохранения игрока не тронуты
(байт в байт). Снимки — `<экран>_<ширина>x<высота>.png`; их смотреть глазами. Итог — «UICHECK ok».

## Что осталось

- Главное меню, пауза кампании и гонки сделаны раньше по своим макетам и на `MGUI` не переведены.
- Шрифты текста — системные (Segoe UI, Consolas, Georgia); на машине без них Godot возьмёт запасные из списка.
