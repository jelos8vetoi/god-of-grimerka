# Форматы музыки в iPod

iPod (`ipod.gd`, автор Shur) принимает свои треки через «Добавить музыку». Импортом занимается
`audio_import.gd` (`AudioImport`, узел `ipod.importer`): проверяет файл по содержимому, решает,
как его подготовить, читает теги и обложку, кладёт копию в `user://ipod_music`. Играет iPod всегда
то, что умеет сам Godot: MP3, Ogg Vorbis, WAV.

## Что берём

| Формат | Расширения | Как готовим | Теги |
|---|---|---|---|
| MP3 | `.mp3` | копия как есть | ID3v2.3/2.4: название, исполнитель, альбом, обложка (`id3.gd`) |
| Ogg Vorbis | `.ogg`, `.oga` | копия как есть (проверяем, что внутри именно Vorbis) | — |
| WAV PCM / float | `.wav` | копия как есть | `LIST/INFO` (INAM, IART, IPRD), `id3 ` |
| WAV со сжатием, WAVE_FORMAT_EXTENSIBLE | `.wav` | декодирует Windows → WAV PCM | как выше |
| AIFF, AIFF-C без сжатия (NONE, twos, sowt, fl32, in24, in32) | `.aif`, `.aiff`, `.aifc` | переписываем в WAV сами (порядок байтов, 8 бит — без знака) | `NAME`, `AUTH`, `ID3 ` |
| M4A — AAC (в т.ч. HE-AAC) | `.m4a`, `.mp4` | декодирует Windows → WAV (длиннее 15 мин — MP3) | iTunes `ilst`: ©nam, ©ART, aART, ©alb, covr |
| M4A — ALAC (без потерь) | `.m4a` | декодирует Windows → WAV | как выше |
| M4B — аудиокниги | `.m4b` | как M4A; длинные — в MP3, чтобы не держать гигабайты WAV в памяти | как выше |
| FLAC (по желанию) | `.flac` | декодирует Windows → WAV | `VORBIS_COMMENT` (TITLE, ARTIST, ALBUM), `PICTURE` |

## Что не берём — и что говорим игроку

| Файл | Причина в сообщении |
|---|---|
| `.m4p`, M4A с `drms` / `drma` / `enca` / `sinf` внутри | защищён DRM (покупка iTunes / Audible) — играть можно только там, где куплен; **защиту игра не снимает и не обходит** |
| `.aa`, `.aax` | аудиокнига Audible с защитой |
| `.wma` | WMA не поддерживается — сохраните в MP3, M4A или FLAC |
| Ogg Opus, `.opus`, FLAC внутри Ogg | кодек не поддерживается |
| расширение не совпадает с содержимым | «по содержимому это не MP3…» |
| пустой, оборванный, без `moov` / `COMM` / `fmt ` | файл повреждён или недокачан |
| больше 1,5 ГБ; WAV / AIFF больше 400 МБ | слишком большой (WAV/AIFF целиком лежат в памяти) |

Сообщение показывается тостом на каждый файл и итогом («Добавлено треков: 3 · не взято: 2»).

## Декодирование без сторонних программ

M4A/M4B/FLAC и сжатый WAV декодирует сама Windows: **Media Foundation** через WinRT
`Windows.Media.Transcoding.MediaTranscoder`. Его вызывает встроенный в Windows `powershell.exe`
со скриптом, который игра пишет в `user://ipod_tools/transcode.ps1` (текст — константа `TRANSCODE_PS1`
в `audio_import.gd`). Ничего не скачивается и не устанавливается; в сборку не входят чужие кодеки
и библиотеки, поэтому новых лицензий нет (см. `godot/THIRD_PARTY.md`).

Безопасность запуска:
- исходник сначала копируется во временную папку `user://ipod_music/.tmp` под простым латинским именем
  (кириллица, пробелы и спецсимволы в пути пользователя до PowerShell не доходят как код);
- `OS.execute("powershell.exe", [аргументы…])` — каждый аргумент отдельной строкой, без командной
  оболочки и без склейки строк; скрипт принимает только три параметра (откуда, куда, формат);
- результат проверяется: файл должен появиться и открыться в Godot (`_playable`), иначе трек не добавляется.

Ограничения: Windows 10/11. На редакциях **Windows N** без *Media Feature Pack* кодеков нет — сообщение
так и говорит. На других системах (если когда-нибудь будет сборка) M4A/M4B/FLAC недоступны, остальное работает.

## Без замираний

Импорт идёт в отдельном потоке (`Thread` в `AudioImport`): игра и интерфейс не стоят. Сигналы
`progress`, `track_ready`, `track_failed`, `finished` приходят в основной поток (`call_deferred`);
iPod добавляет трек сразу, как он готов, и пишет настройки. Выход из игры во время импорта —
`importer.stop()` дожидается потока (`_exit_tree`).

## Имена, оригиналы, чужие треки

- Копия называется `<время>_<случайное>.<mp3|ogg|wav>`; если имя вдруг занято — берётся другое.
  Тот же файл, добавленный дважды, — две разные копии, прежняя не перезаписывается.
- Оригинал только читается: не переименовывается, не меняется, не удаляется.
- Удаление трека в iPod удаляет только его копию и обложку (если она больше ни у кого).
- Временные файлы декодера удаляются сразу после него.

## Проверка

```bash
$G --path godot --resolution 1280x720 -- --ipodcheck=<папка>
```

Раздел `formats_block` в `ipodcheck.gd` сам собирает файлы в папке с кириллицей и пробелом в имени:
M4A (AAC) и M4A (ALAC), FLAC — тем же декодером Windows; M4A с тегами iTunes и PNG-обложкой; M4B;
AIFF с `NAME`/`AUTH`; M4A с меткой `drms`; `.m4p`; `.wma`; Ogg Opus; текст под видом MP3; пустой файл.
Проверяет: что взято и что отказано (с причиной), кодек (AAC / ALAC / M4B), теги и обложку, что каждый
взятый трек играет, что игра не замирала, что оригиналы не изменились (MD5), что повторный импорт
не перезаписал прежний, что после удаления в папке iPod всё как было и временных файлов нет.
