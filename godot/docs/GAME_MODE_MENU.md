# Главное меню и экран «ВЫБОР РЕЖИМА»

GOD OF GRIMERKA — уже не только сюжетный экшен: в игре несколько самостоятельных режимов. Главное меню больше
не держит все активности в одном списке — для них есть отдельный экран выбора режима.

## Структура

```
ГЛАВНОЕ МЕНЮ (menu.gd)
├── CONTINUE          — сразу продолжает сюжетное сохранение (недоступен без сохранения)
├── PLAY              — «ВЫБОР РЕЖИМА» (mode_select.gd)
│   ├── 01 STORY MODE      → CONTINUE · NEW GAME · LOAD GAME · НАЗАД
│   ├── 02 TRAINING ARENA  → прежний экран выбора героя и стиля (menu._open_training)
│   └── 03 VACUUM RACING   → меню гонок (menu.open_race → RaceMenu, docs/VACUUM_RACING.md)
├── SETTINGS
├── EXTRAS
└── EXIT
```

Пункты NEW GAME, LOAD GAME и TRAINING ARENA не удалены — они переехали на экран режимов и работают теми же
функциями меню: `launch(from_save, chapter)`, `_open_load()`, `_open_training()` / `launch_training()`.
Новой системы сохранений нет: STORY MODE читает и запускает то же `user://grimerka_save.json`, арена — свой
`user://grimerka_training.json`. Сам выбор режима ничего не пишет.

## Где что в коде

| Что | Где |
|---|---|
| Пункты главного списка | `Menu.ITEMS` (`[надпись, описание, подпись]`) |
| Открыть / закрыть экран режимов | `menu.open_modes(start)`, `menu.close_modes()` |
| Что делает режим | `menu.open_mode(id)`: `story` → `_open_story()`, `training` → `_open_training()`, `race` → `open_race()` |
| Режимы, тексты, слово-фон | `ModeSelect.MODES` |
| Композиции режимов | `ModeSelect._build_art`, `_scene_training`, `_scene_race` |
| Гонщик на пылесосе (вид) | `race_visual.gd` (`RaceVisual`) — тот же вид, что будет у участников гонки |
| Возврат по Esc на экранах | `menu.panel_back` (NEW GAME и LOAD GAME возвращают на экран сюжета) |
| Гоночный режим | `menu.race_ready()` → `true`: карточка «ДОСТУПНО», меню гонок — `race_menu.gd`; ONLINE RACE — `menu.open_online()` |

Новый режим — строка в `ModeSelect.MODES`, композиция в `_build_art` и ветка в `menu.open_mode`.

## Оформление

- Стол 1600×900 (`menu.stage`), вписывается в любое окно вместе с остальным меню; фон — шейдер меню.
- Слева — заголовок SELECT с плашкой «MODE // ВЫБОР РЕЖИМА» и три карточки: огромный номер, название,
  русская подпись, плашка статуса. У выбранной — рваная белая полоса, красная засечка, текст тушью.
- Справа — композиция режима: настоящие модели игры в своём `SubViewport` через монохромный шейдер с
  полутоном и белым контуром (`Menu.CHAR_SHADER`), огромное слово-фон, рваная красная полоса:
  - STORY MODE — Пахан и madk1d (тот же рендер, что на главном экране, второй не делается);
  - TRAINING ARENA — Пахан с балоном в боевой стойке и манекен-бот в размеченной зоне, красная мишень;
  - VACUUM RACING — Пахан верхом на ТЯГЕ-812 в разгоне и madk1d в заносе, полосы скорости.
- Переход между режимами: прежняя композиция уходит влево и гаснет, новая въезжает справа, по кадру проходит
  белая полоса. Рисуется только выбранная композиция — у остальных `SubViewport` выключен.
- Логотип, главный список, герои, угловые подписи и строка INFORMATION на экране режимов гаснут
  (`menu.main_only`) и возвращаются по Esc.

## Управление

| Действие | Клавиатура | Мышь | Геймпад |
|---|---|---|---|
| Выбор | W / S, стрелки (A / D тоже) | наведение | крестовина, левый стик |
| Открыть | Enter, пробел | клик | A |
| Назад | Esc, Backspace | «◀ НАЗАД» | B |

Esc всегда ведёт на шаг назад: экран режима → экран режимов → главный список. Игру Esc не закрывает.
Геймпад работает через встроенные действия `ui_*`; в Godot 4.7 у `ui_accept` / `ui_cancel` нет кнопок
геймпада, поэтому `main.gd` добавляет им A и B (если их нет). Игровые действия (InputMap кампании) не меняются.

## Проверка

```bash
$G --path godot --resolution 1280x720 -- --modecheck=<папка>
```

`modecheck.gd` идёт как игрок: главный список (клавиши и крестовина), CONTINUE, PLAY, все три режима (клавиши,
наведение и клик мышью, A и B геймпада), STORY MODE (подтверждение NEW GAME с «ОТМЕНОЙ» по умолчанию, LOAD GAME,
настоящий запуск LOAD GAME и NEW GAME с возвратом сохранения), запуск арены, вход в меню гонок, назад по Esc и по
«◀ НАЗАД», SETTINGS, EXTRAS, окна 1920×1080, 1024×768, 2560×1080, 1152×648 (карточки и описание в кадре),
сохранение байт в байт как до проверки и последним — EXIT. Итог — «MODECHECK ok». Снимки — в папке.
